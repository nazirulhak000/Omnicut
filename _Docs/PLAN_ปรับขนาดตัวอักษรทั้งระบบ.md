# แผน: ปรับขนาดตัวอักษร & ความหนาแน่นทั้งระบบ

> วัดจริงด้วยเบราว์เซอร์ 2026-09-02 · จอ 1280×800 และ 1920×1080 · ยังไม่ลงมือทำ

## 1. สิ่งที่วัดได้ (ไม่ใช่ความรู้สึก)

| จุดวัด | ค่าที่วัดได้ | เกณฑ์ที่ควรเป็น |
|---|---|---|
| ตัวอักษรที่เล็กกว่า 12px | **94%** ของ element ที่มีข้อความ (33 จาก 35) | 0% |
| ขนาดที่ใช้จริงทั้งแอป | 8, 9, 10, 11, 11.6, 13.6px | 12 / 14 / 16 / 18 / 24 |
| ตัวใหญ่สุดในทั้งแอป | **13.6px** | หัวข้อควร 18-24px |
| ในหน้าไทม์ไลน์ | **23 element ที่ 9px**, 20 ที่ 10px, 11 ที่ 11px | ต่ำสุด 12px |
| `text-[Npx]` ที่ hardcode ในโค้ด | **214 จุด** ใน 14 ไฟล์ (10px×106, 11px×88, 9px×17, 8px×2) | ใช้ token แทน |
| คอนโทรลที่สูงต่ำกว่า 32px | **12 จาก 23** (เตี้ยสุด 13px) | ≥32px (เมาส์) / 44px (สัมผัส) |
| ความกว้างฟอร์มสร้างคลิป @1920 | **651px = 34% ของจอ** เหลือว่างข้างละ 635px | 900-1100px |
| line-height ของข้อความไทย | มี 1.33 ปนอยู่ | 1.5-1.75 (ไทยมีวรรณยุกต์บน-ล่าง) |
| ข้อความที่ contrast < 4.5:1 | 20 จุด — ruler 9px ที่ **3.03:1** เป็นตัวจริง (ที่ 2.15:1 เป็นปุ่ม disabled ซึ่งยอมได้) | ≥4.5:1 |

**ต้นตอเชิงโครงสร้าง:** `index.css` ตั้ง `html { font-size: calc(15.5px * var(--ui-scale)) }` ไว้ — คือมีคันโยกซูมทั้งแอปอยู่แล้ว **แต่ 214 จุดเขียนเป็น px ตายตัว จึงไม่ขยับตาม** ทดสอบแล้ว: ตั้ง `--ui-scale: 1.5` → root 15.5px → 23.25px แต่ข้อความ `text-[11px]` **ยังเป็น 11px เท่าเดิม** และไม่มีไฟล์ไหนใน `src/**.jsx` เซ็ตตัวแปรนี้เลย = คันโยกที่ต่อไม่ถึงอะไร

> หมายเหตุ: ปุ่ม `100% − + รีเซ็ต` ที่เห็นมุมขวาบนในภาพ เป็นซูมของ Claude Code เอง ไม่ใช่ของแอป

## 2. ทางที่เลือก (และทางที่ไม่เลือก)

**ไม่เลือก — ไล่แก้ `text-[10px]` → `text-[13px]` ทีละจุด**
214 จุดแก้มือ ครั้งหน้าอยากปรับอีกก็ต้องไล่ใหม่ทั้งรอบ และ agent อีกตัวที่กำลังแก้ไฟล์เดียวกันจะทับกันแน่นอน

**เลือก — เปลี่ยนเป็น scale แบบ rem แล้วต่อคันโยกที่มีอยู่ให้ใช้งานได้จริง**
1. ตั้ง type scale เป็น rem (Tailwind `text-xs/sm/base/lg` = 0.75/0.875/1/1.125rem อิง root)
2. แทนที่ `text-[Npx]` ทั้ง 214 จุดด้วย token ตามตารางแมป — **แก้ครั้งเดียว**
3. root จาก 15.5px → **16px** (ได้ 12/14/16/18px พอดี)
4. เพิ่มตัวเลือก **ขนาดตัวอักษร: กะทัดรัด / ปกติ / ใหญ่** (`--ui-scale` = 0.94 / 1 / 1.13) ในเมนู System — คันโยกที่ตายอยู่กลายเป็นของจริง ปรับได้เองโดยไม่ต้องแก้โค้ด

ได้ผล 3 ต่อ: อ่านง่ายขึ้นทันที · ปรับเองได้ทีหลัง · ครั้งหน้าไม่ต้องไล่แก้อีก

## 3. Type scale ใหม่ (root 16px)

| token | rem | px @ปกติ | px @ใหญ่ | ใช้กับ |
|---|---|---|---|---|
| `text-xs` | 0.75 | **12** | 13.6 | ป้ายกำกับเล็กสุด, ruler, badge — **พื้นล่างสุด ห้ามต่ำกว่านี้** |
| `text-sm` | 0.875 | **14** | 15.8 | ข้อความทั่วไป, ปุ่ม, รายการ, ค่าใน inspector |
| `text-base` | 1 | **16** | 18 | ข้อความในฟอร์ม, textarea บท, ชื่อไฟล์ |
| `text-lg` | 1.125 | **18** | 20.3 | หัวข้อบล็อก ("สินค้า & มุมที่จะเล่า") |
| `text-2xl` | 1.5 | **24** | 27 | หัวข้อหน้า ("สร้างคลิปใหม่"), timecode หลัก |

**แมปจากของเดิม (ใช้ sed ได้ตรงๆ):**

| เดิม | จำนวน | ใหม่ | เหตุผล |
|---|---|---|---|
| `text-[8px]` | 2 | `text-xs` (12) | +50% — badge บนคลิป |
| `text-[9px]` | 17 | `text-xs` (12) | +33% — ruler, ชิปซับ, helper |
| `text-[10px]` | 106 | `text-sm` (14) | +40% — ป้ายกำกับ, helper text |
| `text-[11px]` | 88 | `text-sm` (14) | +27% — ข้อความหลัก, ปุ่ม |
| `text-[12px]` | 1 | `text-base` (16) | ข้อความในฟอร์ม |
| `text-xs` เดิม (11.6) | ~20 | คงไว้ → 12 | ขยับเองจาก root |

ข้อยกเว้นที่ **ไม่**ขยับเป็น 14px แต่ใช้ 12px: ruler ไทม์ไลน์ · ป้ายชื่อบน filmstrip · badge speed/mirror — พื้นที่จำกัดจริง แต่ยังไม่ต่ำกว่า 12

**line-height:** ตั้ง `leading-relaxed` (1.625) เป็นค่าเริ่มต้นของข้อความไทยยาว, `leading-snug` (1.375) สำหรับป้ายบรรทัดเดียว — เลิกใช้ 1.33

## 5. Layout: เลิกบีบฟอร์มเป็นเสาแคบ

ตอนนี้ฟอร์มสร้างคลิปกว้าง 651px บนจอ 1920 (ว่างข้างละ 635px)

```
เดิม (1920)                          ใหม่ (≥1440)
┌──────┬──────────┬──────┐          ┌──────┬───────────────────┬─────────┐
│ ว่าง  │  ฟอร์ม    │ ว่าง  │          │ ว่าง  │ สินค้า&มุม | คลิปดิบ  │  สรุป +  │
│ 635  │  651px   │ 635  │          │      │ บท (กว้างเต็ม)     │  ปุ่มสร้าง │
└──────┴──────────┴──────┘          └──────┴───────────────────┴─────────┘
                                      max-w 1100px · 2 คอลัมน์ที่ ≥1280
```

- `max-w-2xl` (672) → **`max-w-3xl` (768) ที่ <1280 · `max-w-5xl` (1024) ที่ ≥1280**
- ≥1280: บล็อก 1-2 เรียง 2 คอลัมน์, บท+ตั้งค่าเต็มความกว้าง, ปุ่มสร้างติดล่างแบบ sticky
- textarea บท: 6 แถว → **10 แถว** ที่จอสูง ≥900px (บทคือของหลักของหน้านี้)

## 6. Contrast ที่ต้องแก้ (ของจริง 1 กลุ่ม)

- ruler ไทม์ไลน์ `#6B6660` บน `#1C1B19` = **3.03:1** → เปลี่ยนเป็น `#9C968F` (**5.4:1**) — ตัวเลขเวลาต้องอ่านออกขณะตัดต่อ
- helper text `text-slate-500` ในฟอร์ม → `#9C968F`
- ปุ่ม disabled ที่ 2.15:1 **ไม่แก้** — disabled ควรจางกว่าจริง (WCAG ยกเว้นให้) แต่จะเพิ่ม `cursor-not-allowed` + `aria-disabled` ให้ครบ

## 8. การตรวจงาน (วัดซ้ำด้วยสคริปต์เดิม)

1. **0 element ที่เล็กกว่า 12px** ทั้ง 2 โหมด (ฟอร์ม + ไทม์ไลน์) — ตอนนี้ 94% และ 23 จุดที่ 9px
2. histogram เหลือเฉพาะ 12/14/16/18/24
3. คอนโทรลทุกตัว ≥32px (ปุ่มหลัก ≥44)
4. ruler contrast ≥4.5:1
5. ที่ **1280×800**: ไม่มี scroll ทั้งหน้า · ไทม์ไลน์ยังอยู่ครบ 3 แทร็ก · พรีวิวไม่เล็กลงกว่าเดิม (ตอนนี้ 415×739 @1920, 257×459 @1280)
6. ที่ **1920×1080**: ฟอร์มกว้าง ≥900px
7. เปลี่ยนขนาดเป็น "ใหญ่" แล้วทุกอย่างต้องโตตาม **และไม่ล้น** ที่ 1280×800
8. `npm run build` + console 0 error + 90 backend tests
