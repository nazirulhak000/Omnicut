### [PROMPT-1] ระบบสร้างและปรับแต่ง Hook Template เอง (Hook Studio)

```markdown
ช่วยออกแบบและสร้างระบบ "Hook Templates Studio" ในหน้าตัดต่อ (Editor) ของ OmniCut Pro Studio ให้หน่อยครับ

เป้าหมาย:
ทำให้ผู้ใช้สามารถเลือก, ปรับแต่ง, และบันทึก "สไตล์เปิดคลิป 3 วินาทีแรก (Hook Template)" ได้เองในคลิกเดียว เพื่อเพิ่มยอดคนดู (Retention Rate) บน TikTok ให้สูงขึ้น และลดเวลาจัดแต่งท่อนเปิดคลิปจาก 5 นาที เหลือ 10 วินาที

ขอบเขตที่ต้องการให้ทำ:
1. แถบเลือก Hook Template ในหน้า Editor (Asset Panel หรือ Inspector):
   - มีหมวดหมู่ "Hook Templates" ให้เลือก 5 รูปแบบมาตรฐาน:
     a) "TikTok Problem Card" (การ์ดข้อความจำลองสไตล์คำถามสะกิดใจ พร้อมอิโมจิและพื้นหลังโปร่งแสง)
     b) "Punch Zoom & Glitch" (ภาพสินค้าซูมกระแทกเข้า 1.15x พร้อมเอฟเฟกต์ Whoosh ทันทีที่คำแรกดัง)
     c) "Split Comparison" (ภาพซ้าย-ขวา ปัญหา vs ทางออก พร้อมป้าย PROS/CONS 3D)
     d) "Breaking Urgent" (แถบพาดหัวสีเหลืองนีออนขอบดำ กระพริบเน้นคำด่วน)
     e) "Before & After Reveal" (แถบกวาดเปิดเผยผลลัพธ์)
2. ระบบ Custom Hook Template (สร้างและบันทึกสไตล์ของตัวเอง):
   - ผู้ใช้สามารถปรับ: ฟอนต์, สีพื้นหลังป้าย, อนิเมชันการเด้งเข้า, เสียง SFX ที่จะเล่นพร้อม Hook (Whoosh/Boom/Ding), และสัดส่วนตำแหน่งบนจอ
   - มีปุ่ม "💾 บันทึกเป็น Template ส่วนตัว" เพื่อนำไปใช้กับคลิปต่อๆ ไปได้ทันที
3. ปุ่ม 1-Click Hook Reroll ใน Timeline:
   - ตรงส่วนหัวของคลิป (0:00 - 0:03) มีปุ่มดร็อปดาวน์สลับข้อความ Hook ทางเลือก 3 แบบ (ดึงจาก AI Script Matrix) สลับปุ๊บ พากย์เสียงพรีวิวท่อนเปิดให้ฟังทันที
4. การรักษากฎ Preview = Render (Parity):
   - Hook ทุกแบบที่แสดงใน Canvas 2D ของ SequencePlayer ต้องเรนเดอร์ผ่าน FFmpeg/ASS ได้ตรงกัน 100% ตามกฎ .agents/rules/preview_render_parity.md
```

### [PROMPT-2] โหมดตัดต่อเร็วอัตโนมัติ (Smart Auto-Cut & Voice Slicer)

```markdown
ช่วยพัฒนาฟีเจอร์ "Smart Auto-Cut & Voice Slicer" ในหน้าตัดต่อของ OmniCut Pro Studio ให้หน่อยครับ

เป้าหมาย:
ลดเวลาการเล็มคลิป (Trim) และการวาง B-roll มือ โดยให้ระบบวิเคราะห์ความยาวเสียงพูดและตัดต่อภาพ B-roll ให้พอดีกับประโยคโดยอัตโนมัติ

ฟังก์ชันที่ต้องการ:
1. Auto B-Roll Slicer ตามท่อนเสียงพากย์:
   - เมื่อมีคลิปดิบ (Raw Video) ยาว 1-3 นาที และมีเสียงพากย์ 4-6 ท่อน
   - เพิ่มปุ่ม "⚡ ตัดภาพเข้ากับเสียงอัตโนมัติ (Auto-Fit B-roll)"
   - ระบบจะซอยคลิปดิบออกเป็นท่อนๆ ตามความยาวของแต่ละประโยค พร้อมกระจายช่วงเวลาที่น่าสนใจ (ไม่ใช่เอาแค่ช่วงต้นคลิปยืด)
2. J-Cut Audio Lead-in อัตโนมัติ:
   - เมื่อตัดต่อช็อต B-roll ใหม่ ให้ระบบขยับเสียงพากย์ของประโยคถัดไป (หรือเสียง Whoosh ข้ามฉาก) ให้ดังขึ้นก่อนภาพตัด 150–250ms อัตโนมัติ ตามกฎ .agents/rules/j_cut_rules.md
3. ปุ่ม Quick Split & Ripple Delete:
   - เพิ่มคีย์ลัดและปุ่มที่หัวอ่าน:
     - กด 'S' ตัดคลิปตรงตำแหน่งหัวอ่านทันที
     - กด 'Q' ลบส่วนหน้าหัวอ่านแล้วดึงคลิปข้างหลังติดกันทันที (Ripple Cut Left)
     - กด 'W' ลบส่วนหลังหัวอ่านแล้วดึงคลิปถัดไปติดกันทันที (Ripple Cut Right)
```

### [PROMPT-3] ระบบ Template สไตล์คลิปสำเร็จรูปใน 1 คลิก (One-Click Video Preset)

```markdown
ช่วยพัฒนาระบบ "Global Video Presets (1-Click Styling)" ในหน้าตัดต่อของ OmniCut Pro Studio ให้หน่อยครับ

เป้าหมาย:
ให้ผู้ใช้สามารถเปลี่ยน "มู้ดแอนด์โทน (Look & Feel)" ของทั้งคลิปได้ในคลิกเดียว โดยไม่ต้องมานั่งตั้งค่าฟอนต์ สี แอนิเมชัน และเสียงทีละจุด

สิ่งที่ระบบต้องเปลี่ยนให้อัตโนมัติเมื่อเลือก Preset:
1. ฟอนต์ & ขนาดตัวอักษร: สลับคู่ฟอนต์ Hook และซับไตเติล (เช่น สายมินิมอลใช้ Prompt / สายขายด่วนใช้ Kanit ExtraBold)
2. กฎการไฮไลต์สี Kinetic: สลับโทนสีคำสำคัญ (เช่น สีนีออนช้อปปิ้ง #FFE600 / สีนีออนเทค #22D3EE / สายสุขภาพมินิมอล #34D399)
3. การเคลื่อนไหวซับไตเติล (Motion Effect): เลือกสไตล์คำเด้ง (Pop-in, Word-by-Word Stagger, Fade Slide, Elastic)
4. ออโต้ BGM & SFX Mapping: ดึงเพลงพื้นหลังและเสียงเอฟเฟกต์ตามธีมที่กำหนดใน 02_Assets/ เข้ามาวางในไทม์ไลน์อัตโนมัติ
5. แถบ Presets แนะนำ:
   - ⚡ "TikTok Flash Sale" (ตัวหนา สีเหลือง/แดง จังหวะฉับไว เน้นราคา)
   - 🌿 "Minimal Aesthetic Review" (คลีน โทนขาว/เทา/เขียว ฟอนต์เรียบหรู คลอเพลง Lofi)
   - ⚙️ "Tech Specs Deep Dive" (โทนไซเบอร์ ดำ/ฟ้า ขอบชัดเจน ป้ายสเปก 3D)
   - 💥 "Pain Point & Problem Solver" (เปิดด้วยการ์ดปัญหา ป้าย Warning สีแดง)
```

### [PROMPT-4] ตรวจสอบและกำจัดจุดสะดุดในหน้า Editor (UI/UX Friction Audit)

```markdown
ช่วยตรวจสอบและปรับปรุง UX/UI หน้าตัดต่อ (frontend/src/components/editor/) เพื่อลดจำนวนคลิกและทำให้ทำงานได้ลื่นไหลที่สุด

กติกาการตรวจ:
1. เปิดหน้า Editor บนเบราว์เซอร์จริง ทดสอบกับโปรเจกต์จริง
2. นับจำนวนคลิก (Click Count) ในการตัดต่อ 1 คลิป ตั้งแต่นำเข้าคลิป จัดซับไตเติล ใส่ปก จนถึงกด Render
3. หาจุดที่ทำให้ผู้ใช้เสียเวลา (Friction Points):
   - ปุ่มหรือคำสั่งไหนที่ต้องคลิกซ้ำๆ บ่อยเกินไป?
   - มีจุดไหนที่พรีวิวช้าหรือกระตุกเวลาลากไทม์ไลน์หรือไม่?
   - ข้อความหรือ Safe Zone 420px มีเครื่องมือช่วยไกด์บนหน้าจอที่ชัดเจนหรือยัง?
4. สรุปแนวทางแก้ไข พร้อมเขียนโค้ดปรับปรุงปุ่ม Quick Toolbar และลดทอนขั้นตอนที่ไม่จำเป็นทันที
```
