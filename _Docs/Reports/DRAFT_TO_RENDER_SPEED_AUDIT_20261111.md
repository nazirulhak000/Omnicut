## 0. สิ่งที่ต้องรู้ก่อนอ่านตัวเลข

1. **เครื่องที่วัดไม่ใช่สเปกที่ระบุไว้** เครื่องที่ session นี้รันอยู่คือ AMD Ryzen 7 7735HS (8 cores / 16 threads), RAM 13.7 GB, การ์ดจอ AMD Radeon ในตัว ไม่มี NVIDIA ไม่มี CUDA
   - `h264_nvenc` เปิดไม่ได้ ระบบเลือก `h264_amf` เอง (ผ่านเกณฑ์ SSIM 0.974)
   - `.venv` ไม่มี `faster-whisper` / `ctranslate2` ขั้นจัดเวลาคำ (word alignment) จึง**ถูกข้ามทุกครั้ง**พร้อมคำเตือนใน log
   - AGENTS.md ข้อ 21 และ 24 เขียนว่าเครื่องมี 20 cores / RTX 4060 / 32 GB ซึ่งไม่ตรงกับเครื่องนี้
   - ผลคือ: ข้อที่เกี่ยวกับ NVENC, CUDA, VRAM **วัดไม่ได้ในรอบนี้** ส่วนคอขวด 3 อันดับแรกเป็นงาน CPU/เครือข่าย จึงมีผลกับทุกเครื่อง
2. **ไม่มีโปรเจกต์ 60 วินาทีในเครื่อง** โปรเจกต์จริงยาว 22–47 วินาที ใช้ `HOY01-โปรไฟลุก_1` (43.6 วิ, 7 คลิป, ต้นทาง 1080x1920 60fps 517 MB) เป็นตัวอย่าง ร่างใหม่ที่สั่ง `target_duration=60` ได้บทยาวแค่ 31.7 วิ
3. **จำนวนรอบไม่ครบ 3 ทุกขั้น** ขั้นที่ยิง Gemini วัดเท่าที่จำเป็น ระบุจำนวนรอบ (n) ไว้ทุกแถว
4. **ส่วน editor (B) ยังไม่ได้วัดในเบราว์เซอร์** ไม่มีตัวเลข React Profiler / INP ข้อค้นพบส่วนนั้นมาจากการอ่านโค้ดเท่านั้น
5. **ยิง Gemini จริงไป:** TTS 5 ครั้ง, สร้างบท 1 ครั้ง, วิเคราะห์โทนบท (text) อย่างน้อย 1 ครั้ง (สูงสุด 5), Vision 0 ครั้ง ในนั้น TTS 4 ครั้งเป็นการยิงที่ไม่ได้ตั้งใจ (ดูข้อ 4.9)
6. `01_Raw/` `02_Assets/` ไม่ถูกแตะ (ลายนิ้วมือขนาด+เวลาแก้ไขของ 2,106 ไฟล์ก่อน/หลังตรงกัน) ไม่มีไฟล์ลง `04_Exports/` หรือ `export_registry.json`
