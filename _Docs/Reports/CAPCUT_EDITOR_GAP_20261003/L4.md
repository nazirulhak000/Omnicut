# L4 Audio: OmniCut Editor เทียบ CapCut (รอบตรวจ read-only 2026-10-03)

ดำเนินการโดย: Claude Code (Claude Sonnet 5.5) เลน L4 Audio
ขอบเขต: เสียงทั้งหมดใน editor (Timeline audio lanes, AssetPanel แท็บ "เสียง", Inspector, preview ใน SequencePlayer, และ backend ที่ render เสียงจริง)
งาน Task Benchmark ที่รับผิดชอบ: T6

## ข้อควรรู้ก่อนอ่าน (ระดับความเชื่อถือของรายงานนี้)

- **ไม่ได้รัน dev server / harness / กดปุ่มใน UI เลย** ทุกแถวคอลัมน์ "ลองกดจริง" จึงเป็น "ไม่" ยกเว้นที่ระบุว่า "วัดด้วย ffmpeg" (วัดไฟล์เสียง ไม่ได้กด UI) ข้อสรุปฝั่ง OmniCut มาจากการอ่านโค้ดไล่ตั้งแต่ UI -> state -> save payload -> backend render
- **ไฟล์ที่มี diff ค้างของเอเจนต์อื่น** (เลขบรรทัดอาจขยับ): `SequencePlayer.jsx` (456+/120-), `EditorShell.jsx`, `AssetPanel.jsx` ส่วน `Timeline.jsx`, `audioPeaks.js`, `beatGrid.js`, `silenceRipple.js`, `ClipInspector.jsx`, `ProjectInspector.jsx`, `sfx_manager.py`, `video_editor.py`, `audio_mix_stage.py` **ไม่มี diff ค้าง** ณ เวลาตรวจ
- **ข้อมูลจริงที่ใช้ประกอบการประเมินผลกระทบ** (อ่านอย่างเดียวจาก `03_Projects/*/project.json` 66 โปรเจกต์ ไม่เขียนอะไร): voice engine = `gemini_tts` 66/66, ใช้เสียงคนจริง 0/66, มี SFX ใน cue 65/66, clip original audio volume > 0 อยู่ **0/65**, `bgm_name` = `tiktok_upbeat_bgm(.wav)` 64/66, `bgm_volume` = 0.12 ใน 43 โปรเจกต์, `bgm_ducking` = true 44/66
- หลักฐานฝั่ง CapCut: เปิดอ่านหน้า capcut.com อย่างเป็นทางการได้ 3 หน้า (ระดับ B) ที่เหลือเป็น C ("น่าจะ") ต้องให้ผู้ใช้ส่งภาพหน้าจอยืนยัน (ส่วน 5) ไม่ได้เปิดไฟล์ภายในของ CapCut
- ไม่ได้ใช้ Jev (`tools/jev_advisor.py`) ลำดับความสำคัญในส่วน 3 เป็นดุลยพินิจของเอเจนต์เอง ไม่มีค่า confidence ให้อ้าง

แหล่งอ้างอิง CapCut ที่ใช้ในรายงาน:
- [B1] https://capcut.com/resource/ai-audio-enhancer : แท็บ Audio มี Noise reduction, Loudness normalization, Enhance voice, Vocal isolation, Channels, และกล่าวถึง extract audio
- [B2] https://www.capcut.com/resource/how-to-change-your-voice : Audio > Voice changer (Voice filters / Voice characters, ปรับ Pitch และ Timbre), มีปุ่ม Extract audio
- [B3] https://www.capcut.com/create/audio-ducking-for-clear-dialogue-in-video : บน CapCut Desktop ducking = แยกแทร็กเสียงพูด/เพลงแล้วใส่ volume keyframes เอง ส่วน auto ducking หน้านี้บอกแค่ว่า "mobile lists" และ "อาจต่างตามเวอร์ชัน/แผน" **ไม่ยืนยันว่า Desktop มี**
- [C-blog] https://notjustok.com/article/how-to-add-music-and-sync-it-with-cuts-in-capcut-desktop/ : beat marker (คลิกขวาที่เสียง > Add Beat Markers, กด M วางเอง) แหล่งบุคคลที่สาม จึงนับเป็น C
