## 0. อ่านก่อน: ความน่าเชื่อถือของรายงานนี้

- **ทุกเลนอ่านโค้ดอย่างเดียว ไม่มีเลนไหนลองกดใน browser จริง** (กฎของรอบนี้ห้ามรัน server) คำว่า "มี" ทุกแถวหมายถึง "เห็นโค้ด" ไม่ใช่ "กดแล้วทำงาน"
- **ฝั่ง CapCut ไม่มีหลักฐานระดับ A เลย** (ไม่ได้เห็นหน้าจอ CapCut จริง) มีระดับ B ไม่กี่หน้าจาก capcut.com ที่เหลือเป็นระดับ C ตัวเลขเปรียบเทียบจึงเป็นค่าประมาณ ต้องยืนยันด้วยภาพหน้าจอ (ข้อ 7)
- **ผมสุ่มตรวจเองในโค้ด 3 ข้อ ตรงทั้งหมด:** (1) `AssetPanel.jsx` `TABS` เหลือ 5 แท็บ ไม่มี effects/filter (2) `isEditableTarget` ใน `editorShortcutKeys.js:16` นับ INPUT ทุกชนิดเป็นช่องพิมพ์ (3) `coalesceKey` ไม่มีใครเรียกนอกตัว hook และเทส ส่วนข้ออื่นผมยังไม่ได้ตรวจเอง
- **เลขบรรทัดอาจขยับ:** `SequencePlayer.jsx`, `EditorShell.jsx`, `useEditorHistory.js`, `editorProjectState.js`, `subtitle_engine.py` มี diff ค้างของ Codex
- **ไม่มีไฟล์ซอร์สถูกแก้โดยรอบนี้** (เขียนเฉพาะโฟลเดอร์รายงาน + บล็อกใน TODO.md)

### ข้อค้นพบที่กระทบทั้งรอบ: เครื่องไม่ตรงกับที่แผนสมมติ

ตรวจเครื่องที่รันอยู่ตอนนี้: **Intel i7-14700 + NVIDIA RTX 4060 + RAM 31.7 GB** ไม่ใช่ Ryzen 7 7735HS / CPU-only / 13.7 GB ที่เขียนไว้ใน TODO.md และในแผนรอบนี้
ผลคือ: (ก) กอง "ไม่คุ้มกับ CPU-only" ในข้อ 3 ใช้ไม่ได้ตรงๆ ต้องประเมินใหม่ตามเครื่องจริงที่ผู้ใช้ใช้ทำงาน (ข) เวลาที่เลนวัดเองเป็นค่าที่ดีกว่าเครื่อง AMD (L5 คูณ ~3 เป็นค่าประมาณ) (ค) L5-16/17 (SAM2 ต้อง CUDA) อาจใช้ได้บนเครื่องนี้ แต่ใช้ไม่ได้บนเครื่อง AMD → **ต้องรู้ก่อนว่าผู้ใช้ทำงานจริงบนเครื่องไหน** (ข้อ 8 ข้อ 1)

## 1. คะแนนต่อเลน

**วิธีคิด (หยาบ ใช้เทียบกันเอง ไม่ใช่การวัด):** นับจากตารางส่วน 1 ของแต่ละเลน แถว "เท่า/ดีกว่า" = 1 คะแนน, แถว "มีแต่ด้อยกว่า" (G2 ครึ่งเดียว, G3 ช้ากว่า, G4 ไม่แม่น, G5 ไม่ลื่น, G6 หาไม่เจอ) = 0.5, แถว "ไม่มี" (G1) = 0 แล้วหารจำนวนแถว (ไม่ตัดแถว "ไม่ควรทำ" ออก จึงค่อนต่ำกว่าความจริงเล็กน้อย) น้ำหนักเลนเป็นดุลพินิจของผม ถ่วงตามความถี่ในงานรีวิวสินค้า 30–90 วินาที

**รวมถ่วงน้ำหนัก ≈ 53%** สำหรับงานรีวิวสินค้า (ไม่ใช่ % ของฟีเจอร์ทั้งหมดของ CapCut) อ่านเป็น "ครึ่งๆ" เท่านั้น เพราะฝั่ง CapCut ส่วนใหญ่ยังไม่ยืนยัน

## 2. ธีมใหญ่ที่เห็นข้ามหลายเลน

**ธีม A: "ปุ่มหลอก / Preview ≠ Render"** (ผู้ใช้เขียนโค้ดไม่เป็น ตรวจเองไม่ได้ ผลเสียหนักกว่าฟีเจอร์ที่หายไป) ที่เจอ:
- ปุ่ม Bold/Italic/Underline และจัดแนวในซับเป็น `useState` ล้วน ไม่ส่งถึง render (L3-03; ผมยืนยัน `CaptionInspector.jsx:99-100`)
- "ปรับเฉพาะกล่องนี้" ของซับเห็นแค่ใน preview render อ่านแค่ x,y ต่อท่อน (L3-01)
- ปุ่ม "ตัดช่วงเงียบ" ตัดแต่ภาพ เสียงพากย์/ซับ/SFX ไม่ตาม (L4-01)
- ปุ่มซ่อนซับ/สติกเกอร์/cutout เป็นของ preview อย่างเดียว ไม่เข้า undo ไม่ถูกบันทึก (L1-09)
- keyframe ที่ pipeline ใส่ให้ซ่อนอยู่และทับ slider ซูม/เลื่อน (L2-01)
- แท็บเอฟเฟกต์/ฟิลเตอร์ในคลังหายจาก UI ทั้งที่โค้ดยังอยู่ (L5-01 = L7-03; ผมยืนยัน)
- โค้ด lock/link/multi-select ไม่ถูกเรียกจาก UI เลย (L1-15) → รายงาน audit รอบก่อนที่นับว่า "มี" ต้องแก้
- effect ใน preview วนซ้ำ แต่ render ไม่วน (L5-02); สติกเกอร์ preview มี fade-in 0.3 วิ แต่ render ไม่มี (L3-09)

**ธีม B: เจอซ้ำหลายเลน (ความเห็นตรงกัน = เชื่อถือได้ขึ้น)**
| เรื่อง | เลนที่เจอ |
|---|---|
| ไม่มีคัดลอก-วางการตั้งค่าคลิป (T11 ~18–33 การกระทำต่อ 3 คลิป) | L1-03, L2-02, L7-05 |
| undo ท่วม เพราะ `coalesceKey` ไม่มีผู้เรียก (ผมยืนยัน) | L2-05, L3-10, L7-01 |
| แท็บ effects/filter เข้าไม่ถึง | L5-01, L7-03 |
| ความแม่นระดับเฟรม/timecode | L1-06, L6-10 |
| ไม่มี UI คีย์เฟรมทั้งที่ render ทำงาน | L2-03, (L1-14 split แล้ว keyframe เพี้ยน) |
| preview 540p/proxy ไม่ตรง render | L6-18, L6-08 |

**ธีม C: สิ่งที่ OmniCut ดีกว่า CapCut (กันสรุปเอียง)** Ghost Reveal และซับ kinetic, auto caption จาก script+TTS, รายการซับแบบ word-processor, ข้อความหลังสินค้า (CapCut ต้องซ้อนหลายแทร็ก), 24 เทมเพลต, ป้ายฮุก 3 ชั้น, SFX ผูกกับข้อความ, ripple delete เท่ากันที่ 6 ขั้น (T1), speed 2 ขั้น (T2), batch render/schedule/auto pipeline
