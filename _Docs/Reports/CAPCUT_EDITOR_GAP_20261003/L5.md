## 0. ขอบเขต วิธีตรวจ และข้อจำกัดที่ต้องรู้ก่อนอ่าน

- **ไม่ได้ลองกด UI จริงเลย** (ห้ามรัน dev server ตามกติกาเลน) ทุกแถวที่ว่า "OmniCut มี" มาจากการอ่านโค้ดครบ 3 ชั้น (โค้ด + จุดที่กดได้ + ที่ backend ใช้ค่านั้นตอน render) ที่ไหนขาดชั้นใดจะลดเป็น "มีครึ่งเดียว" หรือ "ยังไม่ยืนยัน"
- **ทดลอง ffmpeg ด้วยตัวเอง (หลักฐานระดับ A ฝั่ง OmniCut/FFmpeg ไม่ใช่ CapCut)** ผลลง `.tmp/` แล้วลบหมดแล้ว:
  1. `ffmpeg -h filter=xfade` (FFmpeg 8.1.1) ได้ **57 transition** ในตัว
  2. จำลองสาย filter ของ effect (`crop` + `blend multiply shortest=1` + `overlay eof_action=pass`) กับ `fx_checkmark_01.webm` หน้าต่าง 0.5-3.5 วิ ผลคือ effect ปรากฏใน render เฉพาะ **0.50-2.20 วิ** (framemd5 เทียบกับไม่มี effect) ไม่ใช่ครบ 3 วิ
  3. ffprobe ทุกไฟล์ใน `02_Assets/Effects/`: 50 ไฟล์ ความยาว 0.93-24.07 วิ **21 ไฟล์สั้นกว่า 3.0 วิ** และ alpha plane ของ 4 ไฟล์ที่สุ่มมี min=max=255 (ไม่มี alpha จริง)
  4. จับเวลา filter ด้วย `-f null` ที่ 1080x1920 30fps (ดูตารางต้นทุนเวลา render ในส่วน 3)
- **เครื่องที่รัน audit นี้ไม่ใช่เครื่องเป้าหมาย**: `Win32_Processor` = Intel i7-14700 (28 เธรด) + RTX 4060 ไม่ใช่ Ryzen 7 7735HS (16 เธรด, ไม่มี CUDA) ตามสเปก ตัวเลขเวลาที่ผมวัดเองจึงเป็น **ขอบล่าง** ผมประมาณคูณ 2.5-3.5 เท่าสำหรับเครื่อง AMD (ประมาณการ ยังไม่ได้วัดบนเครื่อง AMD) ตัวเลขจากรายงาน Codex/Claude รอบก่อนอ้างตามต้นฉบับพร้อมบอกที่มา
- **เลขบรรทัดอาจขยับ**: `AssetPanel.jsx`, `SequencePlayer.jsx`, `EditorShell.jsx`, `backgroundIsolationPreview.js`, `cutoutVideoPlayback.js`, `background_isolation*.py` มี diff ค้างของ Codex (git status); `cutoutEngineModel.js`, `cutoutSubjectPointState.js`, `subjectPoints.js`, `backgroundIsolationConfig.js`, `background_isolation_sam2_worker.py`, `birefnet_engine.py` เป็นไฟล์ใหม่ที่ยังไม่ commit ผมอ่านอย่างเดียวและไม่เสนอซ้ำกับรายการเปิดของ Codex (P0 พรีวิว 1080p, S0 จุดสินค้าถึง SAM2 GPU, S1 portability/ข้อความ runtime) เสนอเฉพาะช่องว่าง UX เทียบ CapCut
- ไม่ได้เรียก Jev (`tools/jev_advisor.py`) ลำดับความสำคัญในส่วน 3 มาจากการตัดสินของเลนนี้เอง ผู้ใช้ควรตัดสินซ้ำ

## ส่วน 5: ที่ตรวจไม่ได้ / ต้องให้ผู้ใช้ช่วย

### คำถามที่ต้องให้ผู้ใช้ตอบ
1. **ถอดแท็บ "เอฟเฟกต์" และ "ฟิลเตอร์" ออกจากคลังซ้ายตั้งใจหรือไม่?** (commit `fc64b88`, 2026-09-22) ถ้าเปิดแอปแล้วยังเห็นแท็บเหล่านี้ที่ใดที่หนึ่ง แปลว่าผมอ่านเส้นทางพลาด กรุณาส่งภาพหน้าจอแถบแท็บของคลังซ้าย
2. **ใส่ transition 1 จุดแล้วคลิปถัดไปเลื่อนมาก่อนจริงหรือไม่ และซับ/overlay ไม่ขยับตาม?** (L5-05) ขอให้ลองกด F บนรอยต่อกลางวิดีโอที่มีซับ แล้วดูว่าซับเพี้ยนไหม
3. **เครื่อง AMD ที่ใช้ทำงานจริงมี NVIDIA/CUDA หรือไม่?** เครื่องที่ audit นี้ใช้ (i7-14700 + RTX 4060) ไม่ตรงกับสเปกในข้อกำหนด (Ryzen 7 7735HS) ผมจึงไม่ได้วัดเวลา rembg บนเครื่อง AMD ขอให้วัดเอง 1 ช่วงสั้นๆ (เช่น 5 วิ) แล้วคูณ
4. ตัดสินใจเรื่อง **ชนิดของ effect ที่ไม่มี alpha** (L5-12): จะทำ asset ชุดใหม่หรือใช้ colorkey

### ขอภาพหน้าจอ CapCut จากผู้ใช้ (จัดตามเมนู)
- **Transitions**: (ก) แท็บ Transitions ทั้งแผง หมวดทั้งหมด ช่องค้นหา และจำนวนรายการในหมวดหลัก (ข) รอยต่อที่ใส่ transition แล้วบน timeline (มีขอบลากความยาวไหม) (ค) แผงขวาของ transition ที่เลือก: ช่วงของ slider ความยาว, มีตัวเลือกทิศทาง/intensity ไหม, ปุ่ม Apply to all (ง) หลังใส่ transition 1 จุดความยาวรวมของ timeline เปลี่ยนไหม คลิปถัดไปเลื่อนไหม
- **Filters**: แท็บ Filters (หมวด, ภาพตัวอย่าง) และแผงปรับ Strength; filter เป็น track แยกหรือติดคลิป
- **Effects**: แท็บ Video effects (หมวด, ค้นหา, พรีวิวตอนชี้) แผงปรับ parameter ของ effect ที่เลือก และ track effect บน timeline; ตัวอย่าง effect แนว glitch/shake ที่ใช้บ่อย
- **Remove BG บนคลิปสินค้า (ไม่ใช่คน)**: แผง Video → Remove BG ทั้งสามโหมด (Auto removal / Custom removal / Chroma key) และผลของ Auto removal บนคลิปสินค้าจริง 1 คลิป พร้อมเวลาที่ใช้จริง (เพื่ออุดช่อง [B2] ที่ไม่ระบุเวลา)
- **พื้นหลังใหม่**: ขั้นตอนใส่พื้นหลังสี/ภาพใต้วัตถุที่ลบแล้ว (แผงหรือ track ไหน)

### ที่ตรวจไม่ได้ในรอบนี้
- ไม่ได้รัน UI/เซิร์ฟเวอร์/เบราว์เซอร์ จึงไม่ได้ยืนยันด้วยตาว่า (ก) แท็บ effect/filter หายจริง (ข) popover แสดง 8 รายการจริง (ค) ปุ่มจุดสินค้าไม่ขึ้นกับ engine จริง (ง) effect ที่ลากยืดแล้ววนใน preview (จ) ผลของ effect บนฟุตเทจมืด (ฉ) ตำแหน่งที่ UI แสดงผล preflight `sam2_cuda_unavailable` — ทุกข้อมาจากโค้ด
