## ส่วน 5: ที่ตรวจไม่ได้ / ต้องให้ผู้ใช้ช่วย

8. **Help / Tooltip / UI scale ใน Settings** (แถว 34, 45)

### 5.2 สิ่งที่ผู้ใช้ต้องลองกดใน OmniCut (ผมไม่ได้รัน dev server)
