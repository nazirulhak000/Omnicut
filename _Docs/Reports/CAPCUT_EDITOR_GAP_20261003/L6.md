## 0. อ่านก่อน (ข้อจำกัดของรายงานนี้)

1. **เลขบรรทัดอาจขยับ:** `frontend/src/components/SequencePlayer.jsx` มี diff ค้างของ Codex (`git diff --stat` = +456/-120) เลขบรรทัดในรายงานนี้คือ snapshot ที่อ่านวันที่ 2026-10-03 ไฟล์ใหม่ที่ยังไม่ commit (`previewQuality.js`, `highResolutionStillPreview.js`, `editorShortcutKeys.js`) ก็เช่นกัน
2. **ไม่ได้เปิดเบราว์เซอร์/ไม่ได้ลองกดจริงเลย** ทุกแถวคอลัมน์ "ลองกดจริง" = ไม่ เหตุผล: (ก) ตอนตรวจ Codex กำลังรัน full pytest พร้อม Vite/Chromium หลายตัว (เห็น `pytest tests/ ... --basetemp` และ vite ที่พอร์ต 57316/59714/63848 ใน process list) การรัน harness เพิ่มจะแย่ง CPU และทำให้ตัวเลข gate ของ Codex เพี้ยน (เกณฑ์เทส Cutout นับเฟรมเห็นสินค้า >=54/60 น่าจะไวต่อโหลด CPU) (ข) ดูข้อ 3
3. **เครื่องที่ตรวจไม่ใช่เครื่องเป้าหมาย:** เครื่องนี้ = Intel Core i7-14700 (20 คอร์), RTX 4060, RAM 31.7 GiB เครื่องเป้าหมายคือ AMD Ryzen 7 7735HS (iGPU Radeon, ไม่มี CUDA, RAM 13.7 GiB) ตัวเลขวัดจริงทุกตัวที่อ้างในรายงานนี้ (ของ Codex) จึงเป็น **ขอบเขตล่างที่ดีเกินจริง** ไม่ใช่ตัวแทนเครื่องเป้าหมาย
4. **สิ่งที่รันจริง (ปลอดภัย ไม่เขียนไฟล์ถาวร):** `node --test` 6 ไฟล์ (`sequencePlayerFrameScheduling`, `previewQuality`, `clipProxy`, `highResolutionStillPreview`, `cutoutVideoPlayback`, `motion/performanceGuard`) = 58 ผ่าน/0 ตก · `.venv pytest tests/test_preview_render_parity.py` (basetemp ใน `.tmp/` ลบแล้ว) = **188 ผ่าน / 1 ตก** (ดูส่วน 5 ข้อ ข-3) · `ffmpeg` สังเคราะห์ 1 วินาทีใน `.tmp/l6_probe` เพื่อวัดมิติ proxy (ลบแล้ว) เทสเหล่านี้ส่วนใหญ่เป็นการ regex ซอร์ส ไม่ใช่การวัดประสิทธิภาพ
5. **หลักฐาน CapCut:** ไม่มีระดับ A เลย (ยังไม่มีภาพหน้าจอจากผู้ใช้) ที่เป็นระดับ B มี 2 แหล่ง: **[B1]** https://www.capcut.com/help/editing-not-match-displayed (Help Center ทางการ: Proxy Editing อยู่ใน Project Settings, "low-res media for smoother playback but may misrepresent scaling or blur effects", Settings > Draft > Clear Cache) **[B2]** https://www.capcut.com/resource/how-to-add-keyframes-in-capcut (หน้าสอนของ capcut.com ได้จาก snippet ผลค้นหาเท่านั้น ยังไม่ได้เปิดอ่านเต็ม: Space เล่น/หยุด, ลูกศรเดินทีละเฟรม, Ctrl+B ตัด) ที่เหลือ **ระดับ C** รวมถึงรายการคีย์ลัดจากเว็บบุคคลที่สาม **[C1]** https://www.skillademia.com/shortcuts/capcut-shortcuts/ (Home/End, Shift+ลูกศร = 5 เฟรม, J/K/L = ถอย/หยุด/เดินหน้า) และ **[C2]** ผลค้นหา fastshortcuts.com / tutorialtactic.com (Fullscreen = Ctrl+Shift+F) ทุกข้อที่อ้าง C ใช้คำว่า "น่าจะ" และต้องยืนยันด้วยภาพหน้าจอ (ส่วน 5)
6. **ไม่ซ้ำกับงานที่ Codex ค้างอยู่** (TODO.md รอบ PC-MAX-PREVIEW-CUTOUT-INTEGRATION: P0 พรีวิว 1080p, P1 วัด dropped frames/latency/memory เทียบ FFmpeg) รายงานนี้ไม่ออกแบบ/แก้ 1080p playback ซ้ำ แต่ชี้ (ก) ผลต่อเครื่องเป้าหมาย CPU-only (ข) ช่องว่างที่ Codex ยังไม่ได้แตะ
