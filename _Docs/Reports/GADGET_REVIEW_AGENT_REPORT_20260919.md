## Recipe กลางที่ใช้ร่วมกัน

ค่าเริ่มต้น: 30–32 วินาที, แนวตั้ง 1080x1920, 30fps, เสียงบรรยายของช่องเป็นเสียงหลัก

| เวลา | หน้าที่ |

| 0:21–0:27 | ข้อจำกัด/ข้อมูลที่ยังต้องรอยืนยัน |
| 0:27–0:32 | สรุปเหมาะกับใคร + CTA ให้ติดตาม/แสดงความคิดเห็น |

กติกาภาพและเสียง:

- เปลี่ยนภาพทุก 0.8–1.5 วินาทีช่วง Hook และ 1.5–2.5 วินาทีช่วงอธิบาย
- ภาพสินค้า/การใช้งานอย่างน้อย 70% ของคลิป
- ซับ Micro-Burst ครั้งละ 2–4 คำ
- ปิดเสียงต้นฉบับและเพลงของ source เว้นแต่มีสิทธิ์ครบ
- หลีกเลี่ยงการใช้โลโก้/พิธีกร/สไลด์ตัวหนังสือเล็กเป็นภาพหลัก
- ไม่ทำให้ Official footage ดูเหมือนเป็น footage ที่ช่องถ่ายเอง

## Rights gate

สถานะทุก source: `HOLD — PRIVATE ROUGH CUT ONLY`

ต้องมีอย่างน้อย:

1. license/permission ที่ใช้บน TikTok และเชิงพาณิชย์ได้ หรือเหตุผลทางกฎหมายที่ตรวจแล้ว
2. ช่วง in/out ที่อนุญาตให้ใช้
3. commentary ของช่องเป็นสาระหลัก ไม่ใช่เอา footage มาแทนคลิปต้นฉบับ
4. ตัดเพลง/เสียงต้นฉบับ เว้นแต่มีสิทธิ์
5. เครดิตและ URL ต้นทาง พร้อมเก็บหลักฐาน permission
6. ไม่สื่อว่าแบรนด์สนับสนุนหรือรับรองช่อง

การ crop, zoom, mirror, ใส่เสียงใหม่ หรือใช้ Google Flow ไม่ได้ทำให้ลิขสิทธิ์เดิมหายไป
