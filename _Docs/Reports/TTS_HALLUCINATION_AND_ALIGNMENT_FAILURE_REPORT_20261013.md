## ⚠️ 2. รากเหง้าของปัญหา (Root Cause Analysis)

### 2.1 ทำไม Gemini Flash TTS ถึงหลอน (Hallucination)?
- สถาปัตยกรรมเดิมรวมประโยคของตัวละครทั้งหมดในคลิปเดียว เช่น 6 เทิร์น นำมาต่อกันด้วย `\n\n... ...\n\n`
- ใส่ Prompt กำกับเสียงยาวเหยียด:
  ```text
  [Voice style: Playful, flustered, good-natured Southern Thai boyfriend named พี่บ่าว...
   Pronunciation rule: ...
   Strict Acting Rule: ...
   Between each section where you see '... ...' leave a clear 2 second silence.]
  ```
- โมเดล Gemini Audio เป็น Multimodal LLM เมื่อเจอบทบาทและคำสั่งยาวๆ มันไม่ได้มองว่าเป็นแค่อุปกรณ์อ่านหนังสือ (Text-to-Speech) แต่มองว่ามันต้อง **"สวมบทบาทแสดงละคร"** มันจึงมักจะทักทาย, พูดเกริ่นนำเปิดฉาก, หรือออกเสียง `... ...` เป็น "อืม/เอ่อ"

### 2.2 ทำไม `split_by_longest_gaps` ถึงพัง?
- ระบบตัดแบ่งประโยคเดิม อิงเฉพาะความดังของคลื่นเสียง (Amplitude dB Threshold) เพื่อหาช่วงเงียบ $N-1$ จุด
- เมื่อ Gemini พูดบทนำนอกสคริปต์แทรกเข้ามา จะมีช่วงเงียบระหว่างบทนำกับประโยคแรก ทำให้ระบบเข้าใจว่าบทนำนั้นคือประโยคที่ 1
- **ผลลัพธ์:** Audio กับ Transcript จึงเลื่อนหลุด (Desynchronized) ทันที

### 2.3 ทำไมระบบตรวจทานเดิมถึงไม่แจ้งเตือน (False Pass)?
- โค้ดเดิมใช้สูตรวัดการทับซ้อนของตัวอักษร:
  ```python
  exp_chars = set(c for c in expected if "\u0e00" <= c <= "\u0e7f")
  hrd_chars = set(c for c in heard if "\u0e00" <= c <= "\u0e7f")
  overlap = len(exp_chars & hrd_chars) / max(1, len(exp_chars))
  ok = bool(heard) and overlap >= 0.35
  ```
- **จุดบกพร่อง:** ในภาษาไทย อักษรอย่าง ก, น, ม, ย, ร, า, เ, อ ปรากฏอยู่ในเกือบทุกประโยค ทำให้แม้ประโยคจะพูดเพ้อเจ้อ หรือพูดแค่คำว่า "อืม..." ก็สามารถมีตัวอักษรซ้ำกับประโยคจริงเกิน 35% ส่งผลให้การตรวจผ่าน 100% หลอกตา (False Negative)

## 🛠️ 3. สถาปัตยกรรมแก้ไขถาวร (The Permanent Solution)

เพื่อขจัดปัญหานี้ให้หมดสิ้น 100% ไม่ให้เกิดขึ้นอีกตลอดไป เราได้เปลี่ยนผ่านสู่:

### 3.1 สถาปัตยกรรม Isolated Turn-by-Turn Generation
1. **ยิงเจนเสียงแยกรายประโยค (1 Turn = 1 Isolated API Call):**
   - ไม่นำหลายประโยคมาต่อกันด้วย `... ...` อีกต่อไป
   - Prompt สั้น กระชับ ไร้จุดไข่ปลา:
     ```text
     [Voice style: {STYLE}
     Strict Rule: Read ONLY the exact Thai sentence below without adding greetings, monologues, commentary, or stuttering words like เอ่อ or อืม.]

     {text}
     ```
2. **ขจัดความเสี่ยง Turn Shift เป็น 0%:**
   - ไฟล์เสียงแต่ละเทิร์นจะถูกบันทึกตรงกับหมายเลขเทิร์น เช่น `turn_00_F.wav`, `turn_01_F.wav`, `turn_02_M.wav`
   - ไม่ต้องพึ่งพา `split_by_longest_gaps` ที่เสี่ยงต่อการตัดผิดอีกต่อไป
3. **ระบบตรวจสอบและซ่อมแซมอัตโนมัติ (Strict Whisper & Auto-Retry Loop):**
   - ใช้ Faster-Whisper ตรวจสอบความถูกต้องรายเทิร์นด้วย `difflib.SequenceMatcher.ratio() >= 0.75`
   - ตรวจจับคำต้องห้าม (`เอ่อ`, `อืม`, `อุ๊ย`) หากพบข้อผิดพลาด ระบบจะสลับ API Key และสั่งเจนซ้ำทันทีจนกว่าจะได้ไฟล์ที่สมบูรณ์ 100%
4. **การประกอบเสียงและขจัดเสียงซ่า (Audio Assembly & Inter-Turn De-glitch):**
   - นำไฟล์เสียงแต่ละเทิร์นมาผ่าน FFmpeg Audio Filters (F: `asetrate*1.10, atempo=1.20` | M: `atempo=1.32`)
   - ต่อกันด้วยช่วงเงียบมาตรฐาน (0.14s ในตัวละครเดียวกัน, 0.28s เมื่อสลับตัวละคร)
   - ปิดท้ายด้วย `clean_isolated_bursts_in_vo` ขจัดเสียงช็อตหรือเสียงซ่ารอยต่อระหว่างเทิร์น 100%
