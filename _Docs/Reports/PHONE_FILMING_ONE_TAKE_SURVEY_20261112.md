# สำรวจ: ถ่ายด้วยมือถือคลิปเดียว ใช้กับทุกสคริปต์ได้ไหม

ดำเนินการโดย: Claude Code (Claude Opus 5.5) · 2026-11-12 · อ่านโค้ดอย่างเดียว ไม่ได้แก้อะไร

คำถามจากเจ้าของ: ถ่ายเองด้วยมือถือได้ครบทุกขั้นไหม สะดวกไหม และอยากถ่ายคลิปเดียวแล้วใช้ได้กับทุกสคริปต์

## คำตอบสั้น

ได้บางส่วน

- คลิปเดียวใช้กับทุกสคริปต์ได้อยู่แล้ว ถ้าถ่ายแบบอิสระ แล้วไปจัดการต่อบนคอมพิวเตอร์:
  - ตั้งเป็นคลิปตั้งต้นให้ทุกมุม
  - สแกนฉาก
  - แต่ละมุมจะเลือกช่วงจากคลิปเดียวกันไปใช้เอง
- คลิปจากการถ่ายแบบมีไกด์ทีละช็อต ผูกกับมุมเดียว ถ้าเอาไปใช้กับมุมอื่น เรนเดอร์จะล้มหรือตัดผิดจังหวะ
- มือถือยังทำเองไม่ครบทุกขั้น ต้องเริ่มจากคอมพิวเตอร์ และสแกนกับเรนเดอร์ก็ทำบนคอมพิวเตอร์

## ตอนนี้ทำงานอย่างไร

ข้อที่ผ่านการเปิดโค้ดยืนยันซ้ำมีเครื่องหมาย ✔

1. **เริ่มจากคอมพิวเตอร์**
   - กดปุ่ม QR ในแผนถ่ายของมุมหนึ่ง ระบบจะสร้าง session ผูกกับมุมนั้น (`scripts/recording_sessions.py`)
   - มือถือต้องอยู่ใน Wi-Fi วงเดียวกัน
2. **ถ่ายบนมือถือ** (`MobileFilmingPage.jsx`)
   - ถ่ายทีละช็อต แต่ละช็อตหยุดเองตามความยาวที่วางแผนไว้ และมีเสียงนำถ่ายคลอเฉพาะช่วงของช็อตนั้น
   - ไม่อัดเสียงจากไมค์ ✔ (`audio: false`)
   - ถ่ายครบทุกช็อตแล้วจึงอัปโหลด
3. **ไฟล์ที่ได้**
   - ต่อทุกช็อตเป็นไฟล์เดียว: `01_Raw/<product_id>/guided_take_<ts>.mp4`
   - มีไฟล์ข้าง `.guided_take.json` เก็บ `angle_id` และแผนตัดของมุมนั้น
   - ไฟล์นี้ถูกแนบให้มุมนั้นมุมเดียว
4. **ที่เหลือต้องทำบนคอมพิวเตอร์:** สร้างบท, สร้างเสียง/แผนถ่าย, เริ่ม session, สแกนฉาก, เรนเดอร์
5. **ของที่ค้างอยู่**
   - ฝั่ง backend ยังมี endpoint `/api/mobile-studio/*`
   - แต่หน้ามือถือที่เคยเรียกใช้ถูกลบไปใน commit `2a46a500` แล้ว

## การใช้คลิปเดียวกับทุกมุม

- **ปุ่มคลิปตั้งต้นให้ทุกมุม**
  - ปุ่มนี้คัดลอก `selected_videos` ไปให้ทุกมุม ยกเว้นมุมที่กำลังตัดต่ออยู่
  - แต่ไม่เคยบันทึก `product.default_videos` ✔ ทั้งที่ `batch_render.py:750` อ่านค่านี้
  - ผลคือมุมที่สร้างทีหลังไม่ได้คลิปนี้ตามไปด้วย
- **แต่ละมุมเลือกช่วงจากคลิปเดียวกันได้**
  - สารบัญฉากสแกนครั้งเดียวต่อไฟล์ แล้วจับคู่กับบทของแต่ละมุมด้วย keyword โดยไม่ยิง API เพิ่ม
  - ตัวกันไม่ให้ใช้ฉากซ้ำทำงานแค่ภายในมุมเดียว ข้ามมุมยังใช้ฉากเดียวกันซ้ำได้
- **batch render ใช้เฉพาะคลิปแรก** ✔ (`batch_render.py:762` ใช้ `chosen_videos[0]`)

## สิ่งที่ขวางเป้าหมาย "ถ่ายครั้งเดียว ใช้ได้ทุกสคริปต์"

1. **บั๊ก: คลิปจากการถ่ายแบบมีไกด์รั่วไปใช้กับมุมอื่น** ✔
   - `scripts/stages/source_resolution.py:115-119` โหลดไฟล์ `.guided_take.json` โดยไม่เช็ก `angle_id`
   - ถ้าตั้งคลิปนี้เป็นคลิปตั้งต้นให้ทุกมุม มุมอื่นจะเจอ `GUIDED_TAKE_BEAT_MISMATCH` หรือถ้าจำนวนช็อตบังเอิญเท่ากัน จะถูกตัดตามจังหวะของมุมอื่น
2. **แผนถ่าย เสียงนำถ่าย session และจังหวะ ผูกกับมุมเดียวทั้งหมด**
   - ยังไม่มีแผนถ่ายรวมระดับสินค้า
   - "สูตรถ่ายทำ 5 ช็อต" ที่มีอยู่เป็นแม่แบบตายตัว ไม่มีตัวอัดคลิปและไม่มีเสียงนำ
3. **คุณภาพการจับคู่ของคลิปที่ถ่ายอิสระ**
   - ขึ้นกับการสแกนฉากและ keyword
   - หลังถ่ายเสร็จ ระบบยังไม่สแกนฉากให้เอง
4. **มือถือทำเองไม่ครบทุกขั้น:** ไม่มีหน้าอัปโหลด สแกน หรือเรนเดอร์บนมือถือ

## ข้อเสนอ เรียงตามคุณค่า

1. **แก้บั๊กข้อ 1**
   - ใช้ไฟล์ข้างเฉพาะเมื่อ `angle_id` ตรงกับมุม ถ้าไม่ตรงให้กลับไปใช้การจับคู่ด้วยสารบัญฉาก
   - ไฟล์ที่แก้: `stages/source_resolution.py` + เทสต์
2. **แผนถ่ายรวมระดับสินค้า (master shot list)**
   - รวมช็อตของทุกมุมแล้วจัดกลุ่มตามฟีเจอร์ ถ่ายแต่ละฟีเจอร์ครั้งเดียวในเทกเดียว แล้วติดป้ายฟีเจอร์ให้แต่ละช่วงของคลิป
   - แต่ละมุมจับคู่บทกับช่วงตามป้าย แม่นยำโดยไม่ต้องพึ่ง AI
   - ไฟล์ที่แก้: `shot_list_builder.py`, `recording_sessions.py`, `MobileFilmingPage.jsx`
   - นี่คือข้อที่ตอบโจทย์ "ถ่ายครั้งเดียว" ตรงที่สุด
3. **บันทึก `product.default_videos` จริง** และให้มุมที่สร้างใหม่ได้คลิปนี้ตามไปด้วย
4. **สแกนฉากอัตโนมัติ** หลังถ่ายเสร็จหรือหลังอัปโหลดจากมือถือ
5. **ทำหน้ามือถือที่ทำได้ครบ:** เลือกสินค้า → ถ่าย/อัปโหลด → เรนเดอร์ทุกมุม ใช้ endpoint `/api/mobile-studio` ที่มีอยู่
6. **กระจายฉากข้ามมุม** ไม่ให้ทุกมุมใช้ช่วงเดียวกัน และให้ batch render ใช้ทุกคลิปใน `selected_videos` ไม่ใช่แค่คลิปแรก

## ยังไม่ได้ยืนยัน
- ยังไม่ได้วัดคุณภาพการจับคู่ฉากกับฟุตเทจจริง
- คาดว่าช็อตของแต่ละมุมในสินค้าเดียวกันมีแอคชั่นคล้ายกันมาก ถ้าจริง จะสร้างแผนถ่ายรวมได้ง่าย
