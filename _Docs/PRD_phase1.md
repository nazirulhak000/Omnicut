## 4. Scope เฟส 1

### ทำ

1. **Product Intake** — วาง URL Shopee/TikTok Shop → ดึง title/ราคา/รูปจาก public meta → เก็บเป็นการ์ดสินค้า พร้อมสถานะ (`candidate` → `testing` → `validated` → `own_shoot`)
2. **Angle Generator** — สินค้า 1 ตัว → 5-10 มุมเล่า + hook ต่อมุม (ผ่าน AI Bridge)
3. **AI Bridge** — สร้าง prompt พร้อม copy → วางผล JSON กลับ → parse เข้าระบบ (schema ตายตัว เพื่อสลับเป็น API call ทีหลังโดยไม่รื้อ)
4. **Render pipeline** (ของเดิม harden) — edge-tts → ซับ .ass → mix SFX/BGM → MP4 9:16
5. **Preview + Re-roll** — ดูในเบราว์เซอร์ → สุ่มใหม่ทีละส่วน (hook / เสียง / จังหวะตัด) → re-render เฉพาะส่วนนั้น
6. **Publish Kit** — caption + hashtag + ลิงก์สินค้า พร้อม copy ปุ่มเดียว + QR ส่งไฟล์เข้ามือถือ
7. **Post Log** — บันทึกว่าโพสต์อะไรไปเมื่อไหร่ + ฟอร์มกรอกผล 48 ชม. (วิว/ไลค์/คลิกตะกร้า/ยอดขาย)

### ไม่ทำ (เฟส 2+)

- F5-TTS voice clone (รอ GPU)
- Shopee Video export variant
- Shot list / teleprompter สำหรับถ่ายเอง
- AI product scoring / trend feed
- ปฏิทินคอนเทนต์
- Posting API ทุกเจ้า
- CapCut draft (ลบทิ้งถาวร)

## 5. งานรื้อ (technical debt) — ✅ เสร็จ 2026-09-01

**ลบแล้ว** — 7 ไฟล์ CapCut generation (`capcut_generator.py` และลูก 6 ไฟล์) + `CapCutTimelineStudio.jsx` (ยืนยันแล้วว่าเป็น mock — import API 5 ตัวแต่ไม่เรียกสักตัว ปุ่ม Export คือ `setTimeout`+`alert`) + `app.py` (Streamlit เก่า) + 3 ไฟล์ showcase ที่ hardcode path เครื่องเก่า + `f5_tts_engine.py` (dead code หลังตัด F5-TTS — ไม่มีไฟล์ไหนเรียกใช้แล้ว)

**เพิ่มแล้ว** — `requirements.txt` (คัดจาก import จริง ไม่ใช่ freeze ทั้งเครื่อง — ทดสอบติดตั้งใน venv สะอาดผ่านแล้ว), `.env.example`, render concurrency guard (`render_jobs.render_slot` — กันเรนเดอร์ซ้อนกันบนเครื่อง CPU-only 13.7GB RAM)

**บั๊กที่เจอระหว่างทำ** (แก้แล้วทั้งหมด): `.gitignore`'s `.env.*` กิน `.env.example` ไปด้วย, `StudioStep3Audio.jsx` ยังเสนอ F5-TTS ทั้งที่ backend ไม่รองรับ + ใช้ไอคอน `Sparkles` ที่ไม่เคย import (จะ crash ทันทีที่เปิด tab เพราะ `gemini_tts` เป็น default), re-roll เรียก `export_capcut=False` เข้าพารามิเตอร์ที่ถูกลบไปแล้ว (ทุก re-roll จะ TypeError)

**spec-bar overlay (PRD section 8) — ✅ เสร็จแล้ว** — `on_screen` จาก AI script ไหลผ่าน pipeline → cues → `subtitle_engine.py` style `SpecBar` (มุมขวาบน กันชนกับ hook banner/แคปชั่น) → เบิร์นเข้า mp4 จริง ยืนยันด้วยคลิป Esseger จริงแล้ว

## 6. ความเสี่ยงที่ยอมรับร่วมกันแล้ว

## 8. เฉพาะทางสาย IT (มีผลต่อ template จริง)

**สเปคเป็นตัวเลข** → ต้องมี spec-bar overlay แสดง mAh / W / ms / Hz / dB เป็นตัวเลขใหญ่บนจอ ไม่ใช่แค่พูด

**มุมเล่าที่แข็งของ IT** (ใช้แทน template `problem_solution` / `curiosity_tech` ที่มีอยู่):
1. เทียบรุ่น / เทียบราคา — "ตัวละ 199 กับ 899 ต่างกันตรงไหน"
2. ของแท้ vs ของปลอม — "เช็ค 3 จุดก่อนกดซื้อ"
3. ทดสอบจริง — วัดไฟจริง / จับเวลาชาร์จจริง / ทดสอบเสียง
4. สเปคที่คนอ่านไม่เป็น — "PD 20W คืออะไร ทำไมต้องสน"
5. ปัญหาที่คนใช้เจอจริง — สายพัง / แบตเสื่อม / ดีเลย์
6. ของถูกที่ไม่ควรประหยัด — เตือนภัย
7. setup / how-to — ใช้ยังไงให้คุ้ม
8. อัปเกรดคุ้มไหม — สำหรับคนมีของเดิมอยู่แล้ว

**ข้อได้เปรียบเฟส 1**: seller asset ของสินค้า IT มักมีสเปคชีท/รูปตัดขวาง/วิดีโอสาธิตให้อยู่แล้ว → มุม 1, 2, 4, 6, 8 ทำได้โดย**ไม่ต้องถ่ายเอง** เหลือแค่มุม 3, 5, 7 ที่ต้องรอของ (เฟส 2)
