## เป้าหมาย

สร้างบัญชี TikTok ใหม่ที่เป็นสื่อความรู้และมุมมองด้าน Mobile Accessories, Electronics และ Gadget โดยไม่ผูกกับการปักตะกร้าเป็นหลัก แล้วใช้บัญชีเดิมทำรีวิวสินค้าและปักตะกร้าตาม workflow เดิมต่อไป

## คำสัญญาของบัญชีใหม่

> เล่าเรื่อง Gadget ให้เข้าใจง่าย ก่อนคุณเสียเงินซื้อ

กลุ่มเป้าหมายคือคนใช้มือถือทั่วไปที่อยากได้ Gadget คุ้ม ใช้ง่าย และไม่อยากอ่านสเปกยาว

บุคลิกของช่องคือ “เพื่อนที่ช่วยจับพิรุธก่อนซื้อ Gadget” ใช้หน้าของผู้สร้างเป็นตัวตนหลัก มีเสียงผู้สร้างเป็นแกน และใช้เสียงสังเคราะห์ได้เฉพาะเป็นรูปแบบเสริมที่ไม่ทำให้ผู้ชมเข้าใจผิดว่าเป็นเสียงจริง

### โครงคลิปมาตรฐาน 30–40 วินาที

1. 0–2 วินาที: เปิดหน้าผู้สร้างและ Hook ที่ตั้งคำถามหรือชี้ความเสี่ยง
2. 3–8 วินาที: แสดงหลักฐาน คลิปอ้างอิง หรือภาพสินค้าเฉพาะส่วนที่จำเป็น
3. 9–28 วินาที: อธิบายด้วยเสียงผู้สร้าง พร้อมแยกข้อมูลแบรนด์ ผลทดลอง และความคิดเห็น
4. 29–36 วินาที: สรุปว่าเหมาะกับใครและไม่เหมาะกับใคร
5. 37–40 วินาที: ชวนคอมเมนต์หัวข้อ Gadget ที่อยากให้ตรวจสอบ

## กติกาแหล่งคลิปและ AI

- ลำดับความสำคัญ: คลิปถ่ายเอง, คลิปที่ได้รับอนุญาตหรือ Press kit, คลิปสั้นที่ใช้เพื่อการวิเคราะห์และเพิ่มสาระใหม่
- ห้ามรีโพสต์คลิป Official เต็มคลิปหรือใช้ Google Flow เพื่ออำพรางต้นทาง
- Google Flow ใช้สร้าง B-roll, diagram, reenactment หรือ visual อธิบายที่เป็นผลงานใหม่ของช่อง
- ทุก source ต้องบันทึก `source_url`, `rights_basis`, `creator_or_brand`, `usage_note` และวันที่บันทึก
- ถ้าไม่มีสิทธิ์หรือเหตุผลการใช้งานที่ตรวจสอบได้ ระบบต้องขึ้นสถานะ `source_review_required` และไม่ให้ส่งเป็น ready-to-publish โดยอัตโนมัติ
- การใช้เสียง/หน้า AI ต้องไม่ทำให้ผู้ชมเข้าใจผิดว่าเป็นเหตุการณ์หรือคำพูดจริงของบุคคลอื่น

## Functional slice แรก

1. สร้าง content project type `gadget_media` แยกจาก project รีวิวปักตะกร้า
2. เพิ่ม campaign `30-day-21-clips` พร้อมรายการ 21 ช่องงานและสถานะ `planned`, `scripted`, `recorded`, `edited`, `published`
3. เพิ่ม source provenance card และ rights gate ก่อน render/export
4. เพิ่ม script template สำหรับสามซีรีส์และ Hook มาตรฐาน
5. เพิ่มฟิลด์วัดผลหลังเผยแพร่: views, completion_rate, comments, follows, follows_per_1000_views
6. ทำให้ preview/export ยังคงสเปก 9:16, 1080×1920, 30 FPS และกฎ subtitle เดิมของโปรเจกต์

## Acceptance criteria

- บัญชีใหม่สร้าง campaign 21 คลิปได้ โดยไม่สร้างรายการปักตะกร้าอัตโนมัติ
- ทุกคลิปมีซีรีส์, Hook, target audience, source list และสถานะงาน
- source ที่ยังไม่ผ่าน rights gate ไม่สามารถถูกทำเครื่องหมาย `ready_to_publish`
- สคริปต์ทุกคลิปแยกข้อมูลแบรนด์, ผลทดลอง และความคิดเห็นได้
- export ทดสอบทั้งหมดลง `.tmp/` เท่านั้น และไม่ทิ้งไฟล์ใน `04_Exports/`
- หลังครบ 21 คลิป สามารถสรุป completion rate และ follows per 1,000 views แยกตามซีรีส์ได้

## ลำดับ implementation

1. สำรวจโมเดล project/campaign/script/export ที่มีอยู่ และเลือกจุดต่อขยายที่ไม่กระทบบัญชีเดิม
2. เพิ่ม domain model และ persistence สำหรับ `gadget_media` campaign
3. เพิ่ม UI สร้าง campaign และจัดการ 21 content slots
4. เพิ่ม source provenance และ rights gate
5. เพิ่ม script templates และ preview metadata
6. เพิ่ม analytics fields และรายงาน 30 วัน
7. รัน deterministic tests, frontend tests, build และตรวจ cleanup ก่อนปิดรอบ
