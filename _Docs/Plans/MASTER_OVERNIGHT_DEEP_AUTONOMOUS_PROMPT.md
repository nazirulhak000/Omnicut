```markdown
- [ ] **1.2 Floating Ambient Orbs (แสงสะท้อนทะลุกระจก):**
  * ติดตั้งเลเยอร์ลูกแก้วแสงนีออน 3 ลูกที่ลอยเคลื่อนไหวอยู่เบื้องหลัง:

    - `orb-indigo`: ขนาด 320px สี `#818cf8` เบลอ 50px แอนิเมชันลอย 12 วินาที
- [ ] **1.3 Master Glass Panels (`.glass-panel` / `.saas-card`):**
  * `backdrop-filter: blur(18px) saturate(195%)`
  * ขอบ 4 ด้านไล่เฉด: ขอบบนขาวคมชัด 0.75, ขอบข้างบาง 0.28, ขอบล่างสีชมพู/ฟ้า 0.40
  * แสงสะท้อน `::before`: เส้นแสง 1px Razor-sharp specular flare ขอบบนช่วง 8% ถึง 92%
  * แสงสะท้อน `::after`: แผ่นไล่เฉดความโค้งมนของกระจกครึ่งบน 38% (Curvature sheen)

## 🔁 ระเบียบการวนลูปการทำงานข้ามคืน (Autonomous Cyclic Protocol)

```
[รอบที่ N]
  1. Audit: สำรวจสถานะปัจจุบันและเลือกหัวข้อยกระดับจาก 6 หมวดข้างต้น

  4. Test: รัน `cd frontend; npm test -- --run` และรัน `pytest` ตรวจสอบความถูกต้อง 100%
  5. Build Check: รัน `cd frontend; npm run build` เพื่อให้แน่ใจว่า Bundle ไร้ข้อผิดพลาด
  6. Commit: ทำ Git commit บันทึกผลงานรอบนั้น
  7. Loop: ขยับเข้าสู่ [รอบที่ N+1] ทันทีโดยไม่ต้องหยุดรอถาม!
