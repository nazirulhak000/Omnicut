# พรอมพ์ตรวจงานหน้า "ตัดต่อมือ" (Editor) — ฉบับละเอียด

วิธีใช้: copy ทั้งบล็อกด้านล่างวางในแชท. ถ้าอยากตรวจแค่บางหมวด ลบหมวดที่ไม่ต้องการออกก่อนวาง.

---

## บล็อกสำหรับ copy

```
ตรวจหน้า "ตัดต่อมือ" (frontend/src/components/editor/) แบบละเอียดทุกจุด

กติกาการตรวจ (สำคัญกว่ารายการ):
- ห้ามบอกว่า "ผ่าน" จากการอ่านโค้ด. ทุกข้อต้องเปิดเบราว์เซอร์จริง กดจริง แล้ววัดค่าจริงมาแสดง (ตัวเลข px / วินาที / จำนวน pixel)
- เจอปัญหา = แก้เลย ไม่ต้องถาม แล้วบอกว่าแก้อะไร วัดผลได้เท่าไหร่ก่อน-หลัง
- อะไรที่แก้ไม่ได้ในรอบนี้ บอกตรงๆ ว่าทำไม อย่าเงียบ
- ทดสอบที่ 2 ขนาดจอ: 1280x800 (จอเล็กสุดที่ใช้จริง) และ 1600x1000
- ใช้โปรเจกต์จริงที่มีคลิปยาว (TikTok_Esseger_สายชารจแมเหลก) ไม่ใช่ข้อมูลปลอม

1. โครงหน้าจอ / ไม่มีอะไรโดนตัด
   - วัด bounding box ทุก pane: asset panel / preview / inspector / toolbar / timeline
   - ทุก element ต้องอยู่ในกรอบ pane ของตัวเอง (bottom <= pane.bottom). แจ้งตัวที่ล้น
   - ทั้งหน้าต้องไม่ scroll (document.scrollHeight เทียบ innerHeight)
   - ปุ่มเล่น + timecode ใต้พรีวิวต้องเห็นครบ ไม่โดนไทม์ไลน์ทับ
   - ลากเส้นแบ่ง (grip) ปรับความสูงไทม์ไลน์: ที่ความสูงต่ำสุดต้องยังเห็นครบ 3 แถว (วิดีโอ/คำบรรยาย/เสียง) ไม่ใช่โดนซ่อนเงียบๆ
   - ปุ่ม "ขยายพรีวิว" → พรีวิวต้องโตขึ้นจริง (วัด px), Esc กลับได้

2. พรีวิวถูกต้องแค่ไหน
   - canvas ต้องได้สัดส่วน 9:16 (0.5625 ± 0.01) ทุกขนาดจอและทุกโหมด
   - ต้องมีภาพจริง ไม่ดำ: สุ่มอ่าน pixel จาก canvas แล้วรายงานอัตราส่วน pixel ที่ไม่ดำ
   - ลากหัวอ่าน (playhead) ไป 5 จุด (0%, 25%, 50%, 75%, 95%) ภาพต้องเปลี่ยนตาม และ timecode ตรงกับตำแหน่ง
   - กด play จริง 5 วินาที: playhead ต้องเดิน ~5 วิ (คลาดไม่เกิน 0.5 วิ) ภาพต้องไม่ค้าง
   - ตรงรอยต่อที่ตั้ง fade: หยุดกลาง fade แล้วเช็คว่าภาพเบลนด์ 2 คลิปจริง ไม่ใช่สลับดิบ
   - คำบรรยายบนพรีวิวต้องไม่ล้นขอบจอ ไม่โดนตัด

3. ไทม์ไลน์
   - ruler: เลข mm:ss ต้องไม่ทับกัน ทุกระดับ zoom (ทดสอบครบ 5 ระดับ)
   - filmstrip: แต่ละคลิปต้องเห็นเฟรมต่างกัน ไม่ใช่ภาพเดียวยืด; วัดเวลาโหลดครั้งแรกกับครั้งที่สอง (cache)
   - ป้ายชื่อคลิปต้องเป็นชื่อไฟล์ ไม่ใช่ path เต็ม
   - ลากขอบคลิปซ้าย/ขวา = trim: ค่า trim_start/trim_end ต้องเปลี่ยนจริง และความยาวรวมต้องอัปเดต
   - ลากสลับลำดับคลิป: ลำดับต้องเปลี่ยนจริงและพรีวิวตามทันที
   - ปุ่มสลับ cut/fade ตรงรอยต่อ: กดแล้วสถานะเปลี่ยน และความยาวรวมลดลง 0.4 วิ ต่อ 1 fade
   - ชิปคำบรรยาย: ลากเลื่อนเวลาได้ ค่า start/end เปลี่ยนตาม ไม่ติดลบ
   - เส้นประท้ายเสียงพากย์: ตำแหน่งต้องตรงกับความยาวเสียงจริง
   - snap: เปิดแล้วขอบคลิปต้องดูดเข้าหา playhead/ขอบข้างเคียงจริง ปิดแล้วต้องไม่ดูด

4. Toolbar + คีย์ลัด (กดจริงทุกปุ่ม ทุกคีย์)
   - แยก (S) / ทำซ้ำ / ลบ (Del) / กลับด้าน / สปีด / undo (Ctrl+Z) / redo (Ctrl+Shift+Z) / zoom (+/-) / snap
   - Space เล่นหยุด, ←/→ เลื่อน 1 เฟรม, Shift+←/→ 1 วินาที, F สลับ fade
   - ปุ่มที่ยังกดไม่ได้ต้อง disabled จริง (มี opacity ลด + กดแล้วไม่เกิดอะไร) ไม่ใช่ปุ่มหลอก
   - undo: ลากขอบคลิปยาวๆ 1 ครั้ง (หลายสิบ event) ต้องถอยกลับด้วย Ctrl+Z ครั้งเดียว ไม่ใช่หลายสิบครั้ง
   - คีย์ลัดต้องไม่ทำงานตอน focus อยู่ในช่องพิมพ์ (พิมพ์ "s" ในช่องข้อความต้องได้ตัว s ไม่ใช่ split)

5. แผงซ้าย (asset) + แผงขวา (inspector)
   - ทั้ง 5 แท็บมีของจริง ไม่ว่าง: คลิป / เสียง / ข้อความ / สติกเกอร์ / ฟิลเตอร์
   - ช่องค้นหาในทุกแท็บกรองผลจริง
   - พรีวิวฟอนต์ต้องเป็นฟอนต์นั้นจริง ไม่ใช่ฟอนต์เดียวกันหมด
   - เลือกคลิป → inspector โชว์โหมดคลิป; เลือกคำบรรยาย → โหมดคำบรรยาย; ไม่เลือก → โหมดทั้งคลิป
   - แก้ค่าในทุกช่อง (trim/speed/mirror/ข้อความ/เวลา) ต้องสะท้อนที่ไทม์ไลน์และพรีวิวทันที
   - คำเตือน "วิดีโอสั้นกว่าเสียง" ต้องโผล่เมื่อสั้นกว่าจริง และหายเมื่อแก้แล้ว

6. Apply / เรนเดอร์จริง (ข้อสำคัญที่สุด)
   - แก้ timeline 3 อย่าง (trim + สลับลำดับ + fade) แล้วกด Apply
   - รอจนเสร็จ แล้ว ffprobe ไฟล์ผลลัพธ์: ความยาวต้องตรงกับที่ไทม์ไลน์บอก (คลาดไม่เกิน 0.3 วิ)
   - เปิดไฟล์ดูเฟรมจริงที่รอยต่อ: ต้องตรงกับที่พรีวิวแสดง
   - แก้เฉพาะคำบรรยาย → ต้องเรนเดอร์แบบ resume ไม่ใช่เริ่มใหม่ทั้งหมด (ดูจาก log/เวลาที่ใช้)
   - ระหว่างเรนเดอร์: ปุ่ม Apply ต้อง disabled + มี % เดินจริง

7. ความสม่ำเสมอของธีม (ห้ามมีสีธีมเก่าหลุด)
   - สแกนทุก element ในหน้า หาสีเก่า #FE2C55 (แดง) / #25F4EE (ฟ้า) / คลาส slate-*
   - สีที่ถูกต้อง: พื้น #181716, panel #232220, จม #1C1B19, เส้น #363430, accent #D97757, ตัวอักษร #EDE9E3 / #9C968F
   - accent ใช้เฉพาะ selection / ปุ่มหลัก / playhead เท่านั้น ห้ามใช้ตกแต่ง

8. สถานะและความปลอดภัยของ UI
   - ทุกปุ่มต้องมีครบ: ปกติ / hover / focus (เห็น ring ชัดตอนกด Tab) / กดค้าง / disabled
   - Tab ไล่ตามลำดับสายตา ไม่กระโดด
   - ยังไม่เลือกโปรเจกต์ / โปรเจกต์ไม่มีคลิป / โหลดพัง → ต้องมีข้อความบอกทางออก ไม่ใช่จอว่าง
   - เปิด prefers-reduced-motion แล้วต้องไม่มี animation
   - เช็ค console: ต้องไม่มี error/warning ของ React (controlled/uncontrolled, key ซ้ำ, act warning)

9. หลังบ้าน
   - python -m pytest scripts/test_phase1_smoke.py ต้องผ่านทั้งหมด
   - npm run build ต้องไม่มี error
   - endpoint /api/editor/filmstrip: ขอ path นอกโฟลเดอร์โปรเจกต์ต้องได้ 403

สรุปท้ายงานเป็นตาราง: หัวข้อ | ผลวัดจริง | ผ่าน/ไม่ผ่าน | แก้อะไรไป
```

## เวอร์ชันสั้น (ใช้ตรวจเร็วหลังแก้ทีละจุด)

```
เช็คหน้าตัดต่อมือที่ 1280x800 และ 1600x1000 ด้วยเบราว์เซอร์จริง โปรเจกต์ TikTok_Esseger:
1) ไม่มี element ล้น pane / ทั้งหน้าไม่ scroll
2) canvas ได้ 9:16 (0.5625 ± 0.01) และมีภาพจริงไม่ดำ
3) กดครบทุกปุ่ม toolbar + คีย์ลัด ปุ่มไหนไม่ทำงานบอกมา
4) ไม่มีสี #FE2C55 / #25F4EE / slate-* หลงเหลือ
5) console ไม่มี error
รายงานเป็นตัวเลขที่วัดได้ ห้ามเดา เจอพังแก้เลย
```
