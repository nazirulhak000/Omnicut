# 🛡️ กฎเหล็กการค้นหาและจัดเก็บวัตถุดิบ (Asset Sourcing & Deduplication Rules)

คู่มือและข้อกำหนดเคร่งครัดในการดาวน์โหลด จัดเก็บ และบริหารจัดการวัตถุดิบ (รูปภาพ/วิดีโอ) สำหรับการผลิตคลิปวิดีโอในโปรเจกต์นี้

---

## ⛔ 1. ข้อห้ามเด็ดขาด (STRICT DON'Ts)

1. ❌ **ห้ามดาวน์โหลดรูปภาพหรือวิดีโอซ้ำซ้อน (Strict Zero-Duplicate Policy)**:
   - ห้ามเซฟภาพหรือคลิปที่มีเนื้อหาเดียวกัน ไฟล์เดียวกัน ลงในโฟลเดอร์โดยเด็ดขาด ไม่ว่าจะตั้งชื่อต่างกันอย่างไรก็ตาม (เช่น ห้ามมีภาพโปสเตอร์เปิดตัวเดียวกัน 5 ไฟล์ในชื่อ `poster_1.png`, `poster_launch.png`, `asset_xxx.png`)
   - ทุกครั้งก่อนดาวน์โหลดหรือเซฟ ต้องตรวจสอบความซ้ำซ้อนผ่าน **URL, File Size หรือ SHA-256 Checksum** เสมอ หากพบว่ามีไฟล์อยู่แล้ว ให้ข้ามการดาวน์โหลดและใช้ไฟล์ที่มีอยู่ทันที

2. ❌ **ห้ามดาวน์โหลดวัตถุดิบข้ามรุ่น หรือรุ่นที่ไม่เกี่ยวข้อง (Strict Single-Product Scope)**:
   - เมื่อได้รับคำสั่งให้ผลิตคลิปสินค้าใด ให้ดาวน์โหลดเฉพาะวัตถุดิบของ **สินค้ารุ่นนั้นรุ่นเดียว 100%**
   - ห้ามดาวน์โหลดสินค้าอื่นใน Ecosystem มารวมแบบสุ่มสี่สุ่มห้า (เช่น สั่งทำ Xiaomi MIX Flip แต่ไปดาวน์โหลด เครื่องดูดฝุ่น, สกู๊ตเตอร์, หม้อทอด, แท็บเล็ต, หรือโทรศัพท์รุ่นอื่นมาดองไว้ในเครื่อง)
   - ห้ามให้มีภาพของแบรนด์หรือรุ่นอื่นหลุดเข้ามาเด็ดขาด (เช่น ห้ามมีภาพแบรนด์ TCL หรือรุ่นอื่นปนในโฟลเดอร์ MIX Flip)

3. ❌ **ห้ามเก็บไฟล์ความละเอียดต่ำหรือภาพแตก (No Low-Resolution / Broken Assets)**:
   - ภาพประกอบต้องมีความละเอียดอย่างน้อย **1080p ขึ้นไป (Full HD / 2.5K)**
   - ห้ามเก็บภาพไอคอนย่อย, ภาพปุ่ม UI เว็บ, ภาพพื้นหลังว่างเปล่า หรือภาพ thumbnail ขนาดเล็ก (<100KB) ที่ใช้ในการตัดต่อไม่ได้

4. ❌ **ห้ามใช้คลิปที่มีซับภาษาต่างชาติฝังเด็ดขาด (Hardcoded Subtitles Prohibition - Rule 12)**:
   - ห้ามใช้ฟุตเทจที่มีซับไตเติลภาษาจีน, เกาหลี หรือภาษาอื่นๆ ฝังในเนื้อวิดีโอ ต้องใช้เฉพาะ Official Design Film หรือ Clean B-roll ที่ภาพสะอาด 100%

## ✅ 2. ข้อปฏิบัติที่ต้องทำเสมอ (STRICT DOs)

1. ✔️ **คัดกรองความซ้ำซ้อนด้วย Script อัตโนมัติ (Automated Deduplication Gate)**:
   - หากมีการดาวน์โหลดจากหน้าเว็บหรือ CDN หลายแหล่ง ต้องรันคำสั่งตรวจสอบ SHA-256 เพื่อลบไฟล์ซ้ำทิ้งทันที
   - ตัวอย่างการตรวจเช็ค:
     ```python
     import hashlib
     file_hash = hashlib.sha256(content).hexdigest()
     if file_hash in existing_hashes:
         continue # ข้าม ไม่บันทึกซ้ำ
     ```

2. ✔️ **ตั้งชื่อไฟล์ให้สื่อความหมายและจัดระเบียบตามประเภท**:
   - `video/`: ฟุตเทจวิดีโอ Clean 1080p+
   - `photos/`: ภาพเรนเดอร์ทางการ, ภาพตัดขวาง Exploded View, ภาพฟีเจอร์เด่น
   - ตั้งชื่อให้อ่านเข้าใจง่าย เช่น `official_design_film.mp4`, `hinge_mechanism.mp4`, `camera_leica_macro.png`

3. ✔️ **ตรวจนับและรายงานสรุปก่อนเริ่มตัดต่อ**:
   - รายงานจำนวนภาพและคลิปที่มีอยู่จริง พร้อมขนาดไฟล์รวม
   - ตรวจสอบว่าทุกไฟล์ตรงรุ่น 100% และไม่มีไฟล์ขยะหลงเหลือ
