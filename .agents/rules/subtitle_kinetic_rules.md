## 🎯 1. นิยามและหลักการสำคัญ (Core Principles)

การดูวิดีโอบน TikTok / Reels ยุคนี้ **กว่า 65% ของผู้ใช้รับชมแบบปิดเสียงในวินาทีแรกๆ** และสายตามนุษย์ถูกดึงดูดด้วยการเคลื่อนไหว (Motion) และสีสัน (Color Contrast) มากกว่าข้อความนิ่ง

### 1.1 Micro-Burst Subtitles (ซับสั้นรัวตามจังหวะลมหายใจ)
- **ห้าม** แสดงประโยคยาวเหยียดเต็มหน้าจอแบบซับหนัง (Subtitle Paragraph)
- **ต้อง** ซอยประโยคเป็นท่อนสั้นระดับ **Micro-Burst (2 – 4 คำ / ไม่เกิน 16 – 24 ตัวอักษร)** ความยาวต่อท่อนประมาณ **0.5 – 1.4 วินาที**
- ตัวหนังสือจะปรากฏและเปลี่ยนผ่านอย่างรวดเร็ว (Rapid-fire Pacing) ตามจังหวะคำพูดของเสียงพากย์จริง

### 1.2 Dynamic Kinetic Highlighting (การไฮไลต์คีย์เวิร์ดทรงพลังด้วยสีและอนิเมชัน ทั้งไทยและอังกฤษ)
- ข้อความทั่วไปจะแสดงเป็น:
  - **ภาษาไทย:** สีขาวบริสุทธิ์ (Solid Pure White `#FFFFFF` / `&H00FFFFFF&`)
  - **ภาษาอังกฤษ:** สีขาวนวลประกายเงิน (`#EAEAEA` / `&H00EAEAEA&`) ขนาด 68% ของภาษาไทย
- เมื่อมี **"คำสำคัญ (Power Keywords)"** ในท่อนนั้น ระบบจะต้อง **ย้อมสีเฉพาะคำนั้นแบบไดนามิก (Inline Color Highlight) ทั้งในภาษาไทยและภาษาอังกฤษคู่ขนานกัน** ด้วยโทนสีนีออนสะดุดตา:
  - 🟡 **สีเหลืองนีออน (`#FFE600` / `&H0000E6FF&`):** สำหรับ Pain Point, ปัญหา, ราคา, ส่วนลด, ตัวเลข, คำกระตุ้น (Default Punch)
  - 🔵 **สีฟ้าไซแอน (`#00E5FF` / `&H00FFE600&`):** สำหรับจุดเด่นสินค้า, สเปกเทพ, เทคโนโลยี, การรับรอง
  - 🔴 **สีส้ม/แดงเตือนภัย (`#FF3B30` / `&H00303BFF&`):** สำหรับคำเตือน, ข้อห้าม, คำว่า "อย่าเพิ่ง", "พัง", "ระวัง"
- **Kinetic Pop Effect:** ตัวหนังสือทุกท่อนต้องมีอนิเมชันเด้งเข้าตาเบาๆ (Snap 125% -> Settle 100% ภายใน 70ms) ผ่านแท็ก ASS `{\fscx125\fscy125\t(0,70,\fscx100\fscy100)}`

## 🗂️ 2. พจนานุกรมคำทรงพลังคู่ขนาน (Bilingual Power Keyword Dictionary)

ระบบจะต้องตรวจจับคำสำคัญทั้ง **ภาษาไทยและภาษาอังกฤษ** เพื่อใส่สีไฮไลต์คู่ขนานกันอัตโนมัติ:

| หมวดหมู่ (Category) | คำสำคัญภาษาไทย (Thai Keywords) | คำสำคัญภาษาอังกฤษ (English Keywords) | โทนสีไฮไลต์ (Color) |
| :--- | :--- | :--- | :--- |
| **1. Pain Point & ปัญหา** | ปวดข้อมือ, ปวดหลัง, ปวดคอ, เมื่อย, ทรมาน, พัง, เหนื่อย, ปัญหา, ช้า, หัก, เสีย | wrist pain, back pain, neck pain, painful, pain, hurt, tight, tired, tiring, problems, broken | 🟡 เหลืองนีออน (`&H0000E6FF&`) |
| **2. คุณสมบัติเด่น & ฮีโร่** | Wave Keys, ไร้สาย, เมมโมรี่โฟม, สรีรศาสตร์, ฮีโร่, คลื่น, นุ่ม, สบาย, รับรอง, ของแท้, 66W | Wave Keys, Logitech, wireless, memory foam, ergonomic, ergonomics, hero, comfortable, comfy, certified, experts, healthy | 🔵 ฟ้าไซแอน (`&H00FFE600&`) |
| **3. ราคา, ดีล, ตะกร้า** | ราคาพิเศษ, ตะกร้า, จิ้มเลย, ลด, บาท, คุ้ม, ของแถม, ฟรี, โปร, พิกัด, อย่ารอ | special price, cart, click now, discount, deal, free, worth it, must have, life-changing, great, best, buy now | 🟡 เหลืองนีออน (`&H0000E6FF&`) |
| **4. คำสั่ง & คำเตือนแรง** | ดูนี่ด่วน, เตือน, อย่าเพิ่ง, หยุด, ระวัง, ลองเปลี่ยน, ด่วนเลย, ต้องมี | look at this, watch this, wait, warning, warn, stop, danger, don't buy | 🔴 แดง/ส้ม หรือ 🟡 เหลือง |

## 📐 3. มาตรฐาน Safe Zone & Typography (9:16 Specification)

```
┌──────────────────────────────┐
│  [ Safe Zone ด้านบน 260px ]   │  <-- Hook Title Header
│                              │
│                              │
│         [ B-Roll ]           │  <-- วิดีโอหลัก 1080x1920
│                              │
│                              │
│  [ Micro-Burst Subtitle ]    │  <-- ซับไตเติลภาษาไทย (ขนาด 78-84px)
│     [ Stacked English ]      │  <-- ซับภาษาอังกฤษรอง (55% scale สีเทา)
│  [ Safe Zone ด้านล่าง 420px ] │  <-- กันปุ่ม TikTok / Title / แคปชัน
└──────────────────────────────┘
```

- **ตำแหน่ง (Position):** Margin Bottom = `420px` (เพื่อไม่ให้ถูกแถบชื่อเพลงและแคปชันของ TikTok บดบัง)
- **Margin ซ้าย-ขวา:** `60px`
- **ฟอนต์มาตรฐาน:** ฟอนต์สไตล์โมเดิร์น ไร้หัว หนาชัด เช่น `Kanit-Black`, `IBMPlexSansThai-Bold`, `Prompt-Bold`
- **ขอบและเงา (Outline & Shadow):**
  - ขอบดำหนาคมชัด `Outline = 5.5px` (`&H00000000&`)
  - เงาคมลึก `Shadow = 2.5px` (`&H80000000&`)
  - การันตีอ่านออก 100% บนพื้นหลังทุกสี ไม่ว่าจะสว่างหรือมืด

## 🛠️ 4. ตัวอย่างการสร้างแท็ก ASS ในโค้ด

```python
# ตัวอย่างการไฮไลต์คำว่า "ปวดข้อมือ" ในประโยค
# ข้อความดิบ: "ทุกคน! ใครปวดข้อมือ"
# ข้อความ ASS ที่ถูกเรนเดอร์:
# "{\fscx118\fscy118\t(0,70,\fscx100\fscy100)}ทุกคน! ใคร{\c&H0000E6FF&}ปวดข้อมือ{\c&H00FFFFFF&}"
```

## 📋 5. เช็คลิสต์ตรวจสอบคุณภาพ (Quality Checklist)

- [ ] ทุกประโยคต้องถูกตัดย่อยเป็น Micro-Burst ไม่เกิน 16-24 ตัวอักษร
- [ ] คำที่เป็นจุดเจ็บ (Pain Point) หรือราคา/ตะกร้าสินค้า ต้องถูกไฮไลต์สีสะดุดตาเสมอ
- [ ] มีอนิเมชัน Kinetic Pop ทุกครั้งที่คำเด้งขึ้นมา
- [ ] ซับภาษาอังกฤษแปลควบคู่ (Bilingual) ขนาด 68% สีขาวนวล `#EAEAEA` และ **ต้องใส่สีไฮไลต์คำสำคัญ (Kinetic Color) คู่ขนานตรงกับภาษาไทยเสมอ (1:1 Cross-Language Parity)**: หากภาษาไทยไฮไลต์คำไหนในหมวดสีใด (เช่น เหลือง หรือ ฟ้า) ซับไตเติลภาษาอังกฤษบรรทัดล่างต้องไฮไลต์คำที่มีความหมายตรงกันในสีเดียวกัน 100% ห้ามมีกรณีภาษาหนึ่งใส่สีแต่อีกภาษาไม่ใส่สีเด็ดขาด
- [ ] รักษาคำแปลภาษาอังกฤษ (Translation Preservation) เมื่อมีการแยกเป็น Smart Clauses หรือ Micro-cues ห้ามลบคำแปลทิ้งเป็นค่าว่าง
- [ ] อยู่ใน TikTok Safe Zone (สูงกว่าขอบล่าง 420px) ไม่ตกขอบจอ
