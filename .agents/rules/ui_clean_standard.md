# 🎨 มาตรฐานการออกแบบ UI & ข้อความปุ่ม (Clean & Unified UI Standard)

คู่มือและกฎเหล็กสำหรับการพัฒนา Frontend (React + Vite, TailwindCSS) ในโปรเจกต์ **TikTok Auto-Cutter Pro Studio** เพื่อให้หน้าตาปุ่ม ข้อความ และสัญลักษณ์ในระบบทั้งหมดเป็นมาตรฐานเดียวกัน คลีน และ **ไม่มีความซ้ำซ้อน 100%**

---

## ⛔ 1. ข้อห้ามเด็ดขาด (Strict UI DON'Ts)

1. ❌ **ห้ามใส่เครื่องหมายบวก `+` นำหน้าข้อความปุ่มที่มีไอคอนอยู่แล้ว:**
   - ❌ **ห้ามทำ:** `<Upload /> + แนบคลิป/รูปเข้าคลัง`
   - ❌ **ห้ามทำ:** `<Upload /> + อัปโหลดคลิปใหม่`
   - ❌ **ห้ามทำ:** `<Plus /> + วิเคราะห์สินค้าใหม่`
   - ❌ **ห้ามทำ:** `<FolderOpen /> + กดเลือกคลิป`
   - 👉 **เหตุผล:** ไอคอนสื่อความหมายของการเพิ่ม/อัปโหลดอยู่แล้ว การใส่ `+` ซ้อนเข้าไปทำให้เกิด `[Icon] + ข้อความ` ซึ่งดูรก ไม่เป็นมืออาชีพ

2. ❌ **ห้ามใส่ Emoji หรือสัญลักษณ์หน้าตัวหนังสือซ้ำกับไอคอนในปุ่ม:**
   - ❌ **ห้ามทำ:** `<Play /> ▶️ เปิดดูในไทม์ไลน์`
   - ❌ **ห้ามทำ:** `<Film /> 👁️ ดูคลิปที่ Export แล้ว`
   - ❌ **ห้ามทำ:** `<Play /> 🎬 เปิดทำต่อในไทม์ไลน์`
   - ❌ **ห้ามทำ:** `<Check /> ✓ บันทึกสำเร็จ`
   - 👉 **เหตุผล:** ไอคอน Lucide ทำหน้าที่สื่อสารทางสายตาแล้ว ข้อความต้องเป็นตัวอักษรคลีน ๆ ไม่ใช้อีโมจิซ้อนไอคอน

3. ❌ **ห้ามปล่อยให้มีปุ่มข้ามสถานะ (Manual Status Bypassing):**
   - ❌ **ห้ามทำ:** ปุ่มเลื่อนคอลัมน์เล่น (`<` หรือ `>`), Drag & Drop การ์ดข้ามไปข้ามมาโดยไม่ได้เรนเดอร์จริง, หรือ Dropdown เปลี่ยนสถานะเล่น
   - 👉 **เหตุผล:** ป้องกันข้อมูลไม่ตรงกับโฟลว์จริง สถานะต้องขยับตามการกระทำจริงเท่านั้น

## ✅ 2. สิ่งที่ต้องทำเสมอ (Strict UI DOs)

1. ✔️ **รูปแบบมาตรฐานของปุ่ม (Standard Button Pattern):**
   - ปุ่มต้องประกอบด้วย **[Lucide Icon]** + **[ข้อความภาษาไทยที่สั้นกระชับ]** เสมอ
   - ข้อความต้องขึ้นต้นด้วยคำกริยาแอ็กชันทันทีโดยไม่มีสัญลักษณ์ใด ๆ นำหน้า:
     ```jsx
     // ✅ ถูกต้องและเป็นมาตรฐานเดียวกันทั้งระบบ:
     <Upload className="w-3.5 h-3.5" />
     <span>แนบคลิป/รูปเข้าคลัง</span>

     <Plus className="w-3.5 h-3.5" />
     <span>วิเคราะห์สินค้าใหม่</span>

     <Play className="w-3.5 h-3.5" />
     <span>เปิดดูในไทม์ไลน์</span>

     <Film className="w-3.5 h-3.5" />
     <span>ดูคลิปที่ Export แล้ว</span>

     <FolderOpen className="w-3.5 h-3.5" />
     <span>เลือกคลิป</span>
     ```

2. ✔️ **การเลือกใช้ไอคอนมาตรฐาน (Standard Icon Mapping):**
   - **อัปโหลด / แนบไฟล์:** ใช้ `<Upload />`
   - **เพิ่มสิ่งใหม่ / สร้างสคริปต์ใหม่:** ใช้ `<Plus />`
   - **เล่นวิดีโอ / เปิดไทม์ไลน์:** ใช้ `<Play />`
   - **ดูวิดีโอ / คลิปที่ตัดเสร็จแล้ว:** ใช้ `<Film />` หรือ `<Play />`
   - **เลือกโฟลเดอร์ / คลังไฟล์:** ใช้ `<FolderOpen />`
   - **ส่งเข้าห้องตัดต่อ / งานโปรดักชัน:** ใช้ `<Clapperboard />`
   - **ยืนยัน / เสร็จสิ้น:** ใช้ `<Check />` หรือ `<CheckCircle2 />`
   - **ทำใหม่ / สลับมุม:** ใช้ `<RefreshCw />`

3. ✔️ **สถานะต้องตรงกับความเป็นจริง 100%:**
   - **`สคริปต์พร้อม` (`scripted`):** สคริปต์พร้อมแต่ยังไม่ได้ส่งเข้าไทม์ไลน์
   - **`กำลังตัดต่อ` (`in_production`):** มีโฟลเดอร์ใน `03_Projects/` แล้ว กำลังปรับแต่งในไทม์ไลน์ แต่ **ยังไม่ได้เรนเดอร์ได้ไฟล์วิดีโอ MP4**
   - **`ตัดต่อเสร็จ` (`rendered`):** ต้องมีไฟล์วิดีโอ MP4 ใน `04_Exports/Ready_to_post/` จริง ๆ แล้วเท่านั้น
   - **`ส่งเข้ามือถือ` (`mobile_ready`):** สแกน QR Code เพื่อโหลดลงสมาร์ตโฟนแล้ว
   - **`โพสต์แล้ว` (`posted`):** โพสต์ลง TikTok แล้วและบันทึกประวัติ
