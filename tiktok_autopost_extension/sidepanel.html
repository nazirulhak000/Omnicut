OmniCut TikTok Post Helper

คลิปที่ตัดต่อเสร็จ (พร้อมโพสต์) ดึงจาก OmniCut Pro Studio โดยตรง

ยังไม่ได้เลือกคลิป — ไปที่แท็บ "รายการคลิป" แล้วกด "เตรียมคลิปนี้" ก่อน
📝 คำอธิบายคลิป (Caption)
🏷️ แฮชแท็ก (Hashtags)
🛒 ID สินค้า (หรือคำค้นหา)

เปิดแท็บ tiktok.com/tiktokstudio/upload ที่ล็อกอินไว้แล้ว กดทำทีละขั้นด้านล่าง เรียงจากบนลงล่าง แล้วสังเกตว่าขั้นไหนทำให้แท็บแครช (ช่องติ๊กจะขึ้นเองเมื่อขั้นนั้นสำเร็จ)

กรอกคำอธิบาย ปักตะกร้า และแนบปกตามลำดับ หยุดทันทีเมื่อพบข้อผิดพลาด จากนั้นตรวจข้อมูลและกดโพสต์ด้วยตัวเอง

อัปโหลดไฟล์ตั้งไฟล์แล้ว detach ทันที ไม่รอ ไม่พิมพ์อะไรต่อ
พิมพ์คำอธิบาย/แฮชแท็กล้างชื่อไฟล์เดิม แล้วพิมพ์แทน
ปักตะกร้าสินค้าค้นหา + แนบลิงก์สินค้าตาม ID ด้านบน
สลับเป็น "กำหนดเวลา"เปลี่ยนโหมดโพสต์ ไม่กดโพสต์จริง
แนบภาพปกจากโปรแกรมเปิดแก้ไขหน้าปก อัปโหลดรูปที่บันทึก แล้วบันทึกบน TikTok
กด Post/กำหนดเวลา⚠️ กดจริง โพสต์ขึ้นจริงถ้ากด

กดปุ่ม "ทำ" ให้ extension ทำขั้นนั้นให้อัตโนมัติ (ช่องติ๊กจะขึ้นเองถ้าสำเร็จ) หรือกดที่ตัวเลข วงกลมได้เอง เผื่อทำขั้นนั้นเองนอกระบบแล้วแค่อยากมาร์คไว้ — ทำทีละขั้น รอผลก่อนกดขั้นถัดไป
