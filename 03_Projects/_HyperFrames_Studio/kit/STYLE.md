## 1. ของจริงก่อนเสมอ ห้ามวาดเอง

| ห้าม (ดูเป็น AI) | ใช้แทน |
|---|---|
| ไอคอน SVG วาดเอง: ลำโพง, ลูกปืน, พระจันทร์, Zzz, โล่, หยดน้ำ | Meme / GIF / ภาพถ่ายจริงที่สื่อเรื่องเดียวกัน (Elmo ชู่ว, ลูกปืน 3D จริง, แมวนอนหน้าพัดลม, เบรกเกอร์ตัด) |
| ฉลาก / ตรา / logo ที่ทำขึ้นเอง | **ไฟล์ทางการ** เช่น ฉลากเบอร์ 5 จาก labelno5.egat.co.th (`assets/shared/img/egat_label_no5_2569.png`) |
| เทอร์โมมิเตอร์ / เกจ / อุปกรณ์ที่เป็นเวกเตอร์ | สติกเกอร์จากภาพถ่ายจริง: GIF ที่ตัดพื้นหลัง (rembg) ทำเป็น sprite แล้วเล่นด้วย `HF.sprite()` |
| การ์ด UI มืดๆ, pill สีฟ้า, glassmorphism | ข้อความ kinetic บนฟุตเทจ + meme card กรอบขาว |

ถ้าหาภาพจริงที่คนดูเห็นแล้วเข้าใจทันทีไม่ได้ (เช่น รูป Thermal Fuse จริงดูไม่ออกว่าคืออะไร) ให้ใช้ **meme ที่สื่อผลลัพธ์** แทน (เบรกเกอร์ตัดพร้อมแว่น "deal with it")

## 2. ไม่มีพื้นหลังสีดำโล่ง

- ทุกช็อตต้องมีฟุตเทจจริงอยู่ข้างหลัง ช็อต hero (สินค้าตัดพื้นหลัง) ใช้เฟรมจริงที่เบลอ ~10px สว่าง ~0.7 **ห้ามกดจนดำ**
- ไม่ใช้รัศมีหมุน / gradient / พื้นสีล้วนแทนฉาก
- Scrim ใช้แค่ radial เบาๆ ให้ตัวหนังสืออ่านออก ต้องยังเห็นฉากอยู่

## 3. Motion ต้องมีฟิสิกส์ ให้รู้สึกจริง

- **Slow-mo ต้องมีเฟรมพอ:** เล่นช้ากว่า 1x ได้เฉพาะเมื่อไฟล์ต้นฉบับมี fps สูงพอ (60fps → 0.5x ได้) ถ้า footage ที่ grade ไว้เป็น 30fps ให้ใช้ rate ≥ 0.8 หรือ grade ใหม่ที่ 60fps (บทเรียนจาก ASMR)

- ของที่ "เกินขีด" ต้องเกินจริง: เทอร์โมมิเตอร์ปรอทพุ่ง → สั่น → **แตก** (หยดปรอทมันวาวกระเด็นแบบมีแรงโน้มถ่วง + แฟลช + เสียงแก้วแตก)
- ตัวเลขนับขึ้น (บิลค่าไฟ, เกจ) ใช้ ease เร่ง แล้วจบด้วยการสั่นแบบเป็นขั้น (deterministic)
- ของที่กระแทกลง (ฉลาก, ตราประทับ) ใช้ `power4.in` ตามด้วยจอสั่นสั้นๆ

## 4. Meme คือจังหวะ ไม่ใช่ของประดับ

- 1 meme ต่อ 1 punchline วางตรงคำที่ตลก (เวลาจาก whisper)
- **Meme pause:** แทรกช่องว่างในเสียงพากย์ 0.6–0.9 วิหลังมุกสำคัญ (`gaps=` ใน build.py) ให้ meme กับ SFX ได้เล่น
- Meme card อยู่ **ชั้นบนสุด** (ต้องอยู่หลัง beat ใน DOM) ไม่ใช่ใต้ scrim หรือ overlay
- Meme SFX คู่กับภาพเสมอ: vine boom, emotional damage, record scratch, airhorn, wow, cha-ching, แก้วแตก (`assets/shared/sfx/`)
- คลัง: `assets/shared/memes/` (GIPHY วนลูปให้ยาวพอ 30fps) ก่อนโหลดใหม่ให้เช็คว่ามีแล้วหรือยัง

## 5. คงไว้จากมาตรฐานช่อง

- ซับคาราโอเกะ Anuphan-Bold ตัวที่พูดเป็นเหลือง `#FFE600` ไม่มีอิโมจิ เวลาจาก whisper เท่านั้น
- ลายน้ำแดงแนวตั้งขวา, ปิดเสียงกล้อง, BGM 0.12 + carve, หัว hook ภาพมืด → สายฟ้า/เปิดตัว
- ข้อความห้ามล้นขอบ: ตัวยาวให้ย่อ font เผื่อวรรณยุกต์ไทย และห้ามชนลายน้ำขวา

## 6. ตรวจก่อนส่ง

- Render draft แล้วดึงเฟรมตาม beat ทุกจุด (ไม่ใช่แค่ `check`): หาดำโล่ง, ของเวกเตอร์หลุดเข้ามา, meme ซีด, ข้อความล้น
- ข้อมูลสินค้า (spec, ดาวบนฉลาก, ประกัน) ต้องตรงกับ listing ห้ามเคลมเกิน
- **ID ห้ามชนกัน:** `c#`/`k#` สงวนไว้ให้ wrapper ฟุตเทจ id ของ beat ให้ขึ้นต้นด้วยชื่อ beat (`cta1`, `hook-…`) เพราะ id ซ้ำทำให้ animation ไปซ่อนฟุตเทจทั้งช็อตจนจอดำ (บั๊กจริงของ Hatari v1)
